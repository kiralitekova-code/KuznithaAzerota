# Умный покупатель — сравнение цен на маркетплейсах

Сравниваем цены на Wildberries, Ozon и Яндекс Маркет в реальном времени. Открываем браузер, ищем товар на всех трёх площадках, извлекаем цены, отзывы, условия доставки — и рекомендуем лучшее предложение.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Когда использовать

- Пользователь спрашивает «Где дешевле купить...?»
- Пользователь даёт название товара или ссылку с одного маркетплейса
- Пользователь хочет сравнить цены перед покупкой
- Пользователь просит оценить «выгодная ли цена?»
- Пользователь хочет проверить отзывы на товар

## Workflow 1: Поиск по названию товара

Пользователь даёт название товара. Ищем на всех трёх площадках одновременно.

### Шаг 1: Подготовка

```bash

node -e "new Promise(r=>setTimeout(r,1*1000)).then(process.exit)"
```

## Workflow 2: Поиск по ссылке

Пользователь даёт ссылку с одного маркетплейса. Нужно найти тот же товар на двух других.

**Шаг 1: Извлечь данные из исходной ссылки** — eval-команды для каждой площадки (Wildberries, Ozon, Яндекс Маркет) — в `references/01-marketplaces.md`.

### Шаг 2: Поиск на других площадках

Используй **название товара + бренд** как поисковый запрос на двух других площадках.

```bash
# Закрыть текущую вкладку
browser-use close

# Искать на следующей площадке
browser-use --headed open "https://www.wildberries.ru/catalog/0/search.aspx?search=<название+бренд>"
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"
# ... (извлечение данных как в Workflow 1)
```

### Шаг 3: Сопоставление товаров

При сопоставлении одного и того же товара на разных площадках проверяй:

1. **Название** — совпадает ли бренд и модель
2. **Характеристики** — вес, объём, комплектация
3. **Артикул/модель** — если указан
4. **Фото** — похоже ли (можно использовать image_analysis)

**Важно**: Не все товары есть на всех площадках. Если товар не найден — сообщи об этом.

## Fallback: данные не извлекаются

Маркетплейсы — тяжёлые SPA с динамическими классами, селекторы ломаются. Если `browser-use eval` вернул пусто, `null` или `NaN`:

1. **Сначала** — упрощённый/универсальный eval (см. «JavaScript Eval Snippets»): `document.querySelector('[class*="price"]')?.textContent`.
2. **Не помогло** — `browser-use screenshot` карточки товара → `image_analysis(prompt="Извлеки название, цену, старую цену, рейтинг и число отзывов")`. Это надёжнее `state` и не забивает контекст.
3. **Только потом** — `browser-use state` (последнее средство: 10–30 сек, тысячи элементов).

Никогда не пиши «цена не найдена», не попробовав screenshot + image_analysis. **Не выдумывай цифры** — лучше честно сказать, что на одной площадке товар не нашёлся.
