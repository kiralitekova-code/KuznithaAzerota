# Сравнительная таблица

Навык для создания структурированных сравнительных таблиц. Применяй его каждый раз, когда пользователь сравнивает 2 и более вариантов или когда ты собрал данные о нескольких объектах.

## Когда использовать

- Пользователь сравнивает варианты («что лучше», «что выбрать», «сравни»)
- Ты собрал данные о 2+ объектах и нужно подвести итог
- Пользователь просит рекомендацию из нескольких вариантов
- Естественный итог любого поиска (автомобили, квартиры, товары, подрядчики)

## Формат таблицы

### Структура

```
| Критерий | Вес | Вариант A | Вариант B | Вариант C |
|----------|-----|-----------|-----------|-----------|
| Цена     | 25% | ⭐ 8/10   | ⭐ 6/10   | ⭐ 9/10   |
| ...      | ... | ...       | ...       | ...       |
| **Итого**|     | **7.4**   | **6.8**   | **8.1**   |
```

### Обязательные элементы

1. **Критерии** — 5–8 параметров сравнения, релевантных задаче
2. **Вес** — значимость каждого критерия (сумма = 100%)
3. **Оценка** — баллы от 1 до 10 по каждому критерию для каждого варианта
4. **Итого** — взвешенная сумма баллов
5. **Вердикт** — 2–3 предложения с рекомендацией

### Типовые критерии по домену

**Автомобили:** цена, пробег, состояние, комплектация, расход топлива, стоимость владения, ликвидность

**Недвижимость:** цена за м², район, транспорт, состояние, инфраструктура, планировка, соседи/дом

**Товары:** цена, качество, отзывы, доставка, гарантия, упаковка, соотношение цена/качество

**Подрядчики:** цена, рейтинг, отзывы, опыт, сроки, гарантия, коммуникация

**Тарифы/услуги:** цена, набор функций, лимиты, поддержка, скрытые платежи, гибкость

**Вакансии:** зарплата, формат работы, стек, команда, рост, локация, баланс

## Весовой скоринг

### Правила весов

- Сумма весов всех критериев = 100%
- Самый важный критерий для пользователя получает наибольший вес
- Спрашивай пользователя о приоритетах, если они не очевидны
- Если приоритеты неизвестны — используй равные веса

### Формула

```
Итоговый балл = Σ (оценка_критерия × вес_критерия / 100)
```

## Блок Pros & Cons

После таблицы добавь краткий блок:

```
✅ **Вариант A** — лучший по цене и доставке, но уступает по качеству
❌ **Вариант A** — слабые отзывы, долгая доставка
✅ **Вариант B** — лучшее качество и гарантия
❌ **Вариант B** — самая высокая цена
```

## Вердикт

Заверши сравнение:

1. **Рекомендация** — какой вариант лучше и почему (2–3 предложения)
2. **Для кого** — кому подойдёт каждый вариант (1 предложение на вариант)
3. **Следующий шаг** — что сделать дальше (позвонить, проверить, уточнить)

## Формат CSV-экспорта

Если пользователь просит экспорт или говорит «в таблицу» / «в эксель» — сгенерируй CSV:

```csv
Критерий,Вес,Вариант A,Вариант B,Вариант C
Цена,25%,8,6,9
Качество,30%,7,9,6
...
Итого,,7.4,6.8,8.1
```

Сохрани CSV-файл и предложи скачать.

## Адаптация под контекст

- Если вариантов больше 5 — покажи топ-3 с полными таблицами, остальные кратко
- Если критериев мало (2–3) — не утяжеляй таблицу, сделай простое сравнение
- Если данные неполные — отмечай gaps как «нет данных» и объясняй влияние на итог
- Всегда показывай расчёт, чтобы пользователь мог проверить
