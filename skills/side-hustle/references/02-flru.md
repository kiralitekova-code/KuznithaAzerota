### Обзор платформы

FL.ru — одна из старейших бирж фриланса в рунете. Проектная модель: заказчик публикует проект, фрилансеры оставляют заявки.

**Когда использовать**: Хорошее дополнение к Kwork для более крупных и долгосрочных проектов. Средний чек выше.

### Поиск проектов

**URL-паттерн:**

```
https://www.fl.ru/projects/?kind=5&pf={price_from}&pt={price_to}&page={page}
```

Параметры:
- `kind` — тип проекта (5 = все, 1 = с конкурсом, 2 = без конкурса)
- `pf` — цена от (в рублях)
- `pt` — цена до (в рублях)
- `page` — номер страницы

**Категории (фильтр по специализации):**

| Параметр | Категория |
|----------|-----------|
| `spec=4` | Программирование |
| `spec=8` | Дизайн |
| `spec=19` | Тексты |
| `spec=38` | Маркетинг |
| `spec=30` | Аудио/Видео |
| `spec=39` | SEO |
| `spec=7` | Переводы |
| `spec=36` | Бизнес |

### Примеры URL

| Запрос | URL |
|--------|-----|
| Все проекты | `https://www.fl.ru/projects/` |
| Программирование | `https://www.fl.ru/projects/?spec=4` |
| Дизайн от 10000 руб | `https://www.fl.ru/projects/?spec=8&pf=10000` |
| Тексты | `https://www.fl.ru/projects/?spec=19` |

### Навигация

```bash
browser-use --headed open "https://www.fl.ru/projects/"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use state
```

**Примечание**: FL.ru может требовать авторизацию для просмотра деталей проектов. Если видишь форму входа:
1. Попроси пользователя войти: «Для просмотра деталей проектов на FL.ru нужно войти в аккаунт. Пожалуйста, авторизуйтесь в браузере.»
2. Дождись подтверждения
3. Продолжи после авторизации

### Извлечение результатов

| Поле | Описание |
|------|----------|
| Заголовок | Название проекта |
| Описание | Краткое описание задачи |
| Бюджет | «10 000 ₽», «По договорённости» |
| Заявки | Количество поданных заявок |
| Срок | Дедлайн или «Не указан» |
| Опубликован | Дата публикации |
| Заказчик | Ник, рейтинг, проекты |
