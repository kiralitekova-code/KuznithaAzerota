# Поиск подрядчиков — Contractor Finder

Поиск исполнителей и подрядчиков одновременно на четырёх крупнейших российских сервисах: **Profi.ru**, **Avito Услуги**, **Яндекс.Услуги** и **YouDo**. Агрегация результатов, дедупликация, скоринг по рейтингам и ценам, проверка репутации, анализ портфолио.

## Обзор

Четыре платформы покрывают ~85% рынка частных услуг в России:

| Платформа | Доля рынка | Особенности |
|-----------|-----------|-------------|
| Profi.ru | ~35% | Крупнейший маркетплейс услуг, рейтинги, верификация, портфолио |
| Avito Услуги | ~30% | Встроен в крупнейший классифайд, много исполнителей, отзывы с покупок |
| Яндекс.Услуги | ~15% | Экосистема Яндекса, проверенные мастера, быстрые ответы |
| YouDo | ~10% | Быстрые задачи, аукцион цен, исполнители с подтверждёнными навыками |

**Стратегия**: Параллельный поиск по всем платформам, дедупликация (один исполнитель часто на нескольких площадках), скоринг и ранжирование по комплексной оценке.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Когда использовать

- Пользователь ищет подрядчика для ремонта, сантехника, электрика, уборку и т.д.
- Пользователь хочет «найти хорошего мастера» или «сравнить цены на услуги»
- Пользователь дал ссылку на профиль исполнителя и хочет проверить его репутацию
- Пользователь хочет оценить стоимость работ до начала поиска
- Пользователь просит «забронировать мастера» или «написать исполнителю»
- Пользователь хочет проверить портфолио и качество работ подрядчика

## Сбор требований у пользователя

Перед поиском уточни:

1. **Тип услуги** — что именно нужно сделать (ремонт, сантехника, электрика, уборка и т.д.)
2. **Город / район** — где нужны работы
3. **Бюджет** — примерная сумма или диапазон
4. **Срочность** — когда нужно начать (срочно, на этой неделе, в течение месяца)
5. **Объём работ** — масштаб задачи (косметический ремонт vs капитальный, одна розетка vs вся проводка)
6. **Особые требования** — лицензии, допуски, опыт с конкретными материалами, язык общения
7. **Предпочтения** — рейтинг от скольки, наличие портфолио, верифицированный исполнитель

Категории услуг, URL-slug (Profi/Avito) и типичные цены — в `references/02-search-commands.md`.

### Шаг 7: Агрегация и дедупликация

Собери все результаты в один список. Проверь на дубликаты:

1. **По имени** — один и тот же мастер на разных площадках
2. **По телефону** — если виден в нескольких профилях
3. **По фото** — одна и та же фотография профиля

При обнаружении дубликата — объединяй данные из всех площадок в одну карточку.

### Шаг 8: Скоринг

Рассчитай оценку для каждого исполнителя:

| Критерий | Вес | Как оценивать |
|----------|-----|---------------|
| Рейтинг | 30% | `(рейтинг / 5) * 100` — баллы от 0 до 100 |
| Количество отзывов | 20% | `min(отзывы / 50, 1) * 100` — максимум при 50+ отзывах |
| Соответствие цене | 20% | Насколько цена вписывается в бюджет пользователя |
| Время ответа | 15% | `< 30 мин = 100`, `< 1 час = 80`, `< 3 часа = 60`, `> 3 часов = 40` |
| Верификация | 15% | Верифицирован на платформе = 100, нет = 30 |

**Итоговый балл** = `0.30 * рейтинг_балл + 0.20 * отзывы_балл + 0.20 * цена_балл + 0.15 * ответ_балл + 0.15 * верификация_балл`

## Правила безопасности

### Никогда не делай

1. **НЕ отправляй формы без подтверждения пользователя** — всегда показывай текст и спрашивай «Отправить?»
2. **НЕ вводи телефон/email пользователя автоматически** — только после явного разрешения
3. **НЕ сохраняй платёжные данные** — никаких реквизитов карт
4. **НЕ нажимай «Оплатить» или «Забронировать»** (если это требует оплаты) без подтверждения
5. **НЕ авторизуйся от имени пользователя** — если нужна авторизация, попроси пользователя войти вручную

### Всегда делай

1. **Всегда закрывай браузер** после завершения: `browser-use close --all`
2. **Всегда используй `--headed`** режим — пользователь должен видеть что происходит
3. **Закрывай модальные окна** перед любыми действиями на странице
4. **Обрабатывай одну площадку за раз** — не открывай несколько вкладок
5. **Проверяй на капчу** и проси пользователя пройти вручную при необходимости

## Советы

1. **Всегда `close --all` первым** — старые сессии — причина зависаний
2. **Жди 4-5 секунд** после навигации — все площадки тяжёлые SPA
3. **Проверяй модалки** перед любыми действиями — особенно на Avito
4. **Используй eval вместо state** — eval в 10 раз быстрее и не забивает контекст
5. **Дедуплицируй** — хороший мастер часто на 2-3 площадках
6. **Проверяй репутацию** — даже при высоком рейтинге на площадке, гугли отзывы
7. **Сравнивай с рынком** — слишком низкая цена = красный флаг
8. **Никогда не отправляй сообщения** без подтверждения пользователя
9. **Анализируй портфолио** через image_analysis — фото говорят больше отзывов
10. **Начинай с Profi.ru** — там больше данных и лучше фильтрация
