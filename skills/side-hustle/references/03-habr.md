### Обзор

Фриланс-биржа от Хабра — качественные IT-заказы от технической аудитории. Средний чек выше, заказчики адекватнее.

**Когда использовать**: Только для IT-специалистов — разработчики, QA, DevOps, дизайнеры интерфейсов, аналитики данных, ML-инженеры.

### Поиск задач

**URL-паттерн:**

```
https://freelance.habr.com/tasks?q={query}&page={page}
```

Дополнительные фильтры:
- `categories[]` — ID категории (см. таблицу)
- `price_from` — минимальная цена
- `price_to` — максимальная цена

**Категории:**

| ID | Категория |
|----|-----------|
| 1 | Программирование |
| 2 | Администрирование |
| 3 | Тестирование |
| 4 | Дизайн |
| 5 | Контент |
| 6 & 7 | Маркетинг / SEO |
| 8 | Аналитика |

### Примеры URL

| Запрос | URL |
|--------|-----|
| Все IT-задачи | `https://freelance.habr.com/tasks` |
| Python-задачи | `https://freelance.habr.com/tasks?q=python` |
| Дизайн интерфейсов | `https://freelance.habr.com/tasks?categories[]=4` |
| React-разработка | `https://freelance.habr.com/tasks?q=react` |

### Навигация

```bash
browser-use --headed open "https://freelance.habr.com/tasks?q=python"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use state
```

Извлеки:
- Название задачи
- Описание (техническое, конкретное)
- Бюджет
- Количество откликов
- Требуемые навыки (теги)
- Срок выполнения
- Рейтинг заказчика
