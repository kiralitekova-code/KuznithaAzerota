## Доступные инструменты

### browser-use CLI

Управление браузером для поиска и извлечения данных с площадок.

```bash
browser-use --headed open "URL"   # Открыть страницу
browser-use state                  # Получить состояние DOM
browser-use click "text=..."       # Кликнуть по элементу
browser-use type "..."             # Ввести текст
browser-use eval "JS"              # Выполнить JavaScript
browser-use keys "..."             # Нажать клавиши
browser-use screenshot             # Скриншот для анализа через image_analysis
browser-use close                  # Закрыть текущую вкладку
browser-use close --all            # Закрыть все вкладки
```

### web_search

Поиск обзоров автомобилей, типичных проблем, рыночных цен, истории VIN.

**Параметры:**
- `query` (string) — поисковый запрос
- `count` (1-50) — количество результатов
- `freshness` ("oneDay" | "oneWeek" | "oneMonth" | "noLimit") — свежесть
- `allowed_domains` (string[]) — ограничение по доменам

### web_reader

Чтение статей с обзорами, технических характеристик, страниц сравнения.

**Параметры:**
- `url` (string) — URL страницы
- `return_format` ("markdown" | "text") — формат возврата
- `retain_images` (boolean) — сохранять ли изображения

### image_analysis

КРИТИЧЕСКИЙ инструмент для этого навыка — анализ фотографий автомобиля на скрытые повреждения, признаки перекраски, состояние салона и подкапотного пространства.

**Параметры:**
- `imageSource` (string) — URL изображения
- `prompt` (string) — что анализировать

## Правила работы с browser-use

### Всегда --headed

Все действия с браузером выполняй только в `--headed` режиме. Пользователь может видеть и взаимодействовать с браузером (проходить CAPTCHA, авторизоваться).

### Закрытие модальных окон

Все три площадки могут показывать модальные окна:
```bash
browser-use keys "Escape"
# или кликнуть вне модала
browser-use eval "document.querySelector('[class*=\"modal\"], [class*=\"popup\"]')?.querySelector('[class*=\"close\"], [aria-label=\"Закрыть\"]')?.click()"
```

### Минимизация вызовов state

`browser-use state` дампит весь DOM — на тяжёлых SPA-страницах это забивает контекст и занимает 10-30 секунд.

**Делай state:**
- В начале работы с каждой новой площадкой (определить структуру)
- Когда eval возвращает неожиданный результат (DOM изменился)
- При навигации на новую страницу

**НЕ делай state:**
- Для получения цены (используй eval)
- Для получения названия автомобиля (используй eval)
- Для извлечения списка объявлений (используй eval)
- Между одинаковыми операциями

### Никогда не отправляй формы

Не нажимай кнопки «Купить», «Отправить», «Позвонить» и т.д. Только чтение и извлечение данных.

### Закрытие браузера

```bash
# После завершения работы
browser-use close --all
```
