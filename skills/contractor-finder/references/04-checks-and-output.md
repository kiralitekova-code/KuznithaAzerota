## Обнаружение мошенничества

При анализе профилей проверяй на красные флаги:

| Признак | Описание | Уровень риска |
|---------|----------|---------------|
| Слишком низкая цена | Цена на 50%+ ниже рынка | Высокий |
| Нет отзывов | Ни одного отзыва при «большом опыте» | Средний |
| Требует предоплату 100% | Просит полную оплату до начала работ | Высокий |
| Нет реального адреса | Только «выезд по городу», без офиса | Низкий |
| Недавняя регистрация | Аккаунт создан менее месяца назад | Средний |
| Одинаковые отзывы | Текст отзывов шаблонный или идентичный | Высокий |
| Нет портфолио | При «10+ лет опыта» нет фото работ | Средний |
| Давление срочностью | «Только сегодня», «Цена действует 1 час» | Высокий |
| Отказ от договора | Не хочет оформлять договор | Высокий |
| Только наличные | Отказ от безналичной оплаты | Средний |

### Проверка подозрительного подрядчика

```bash
# Поиск информации о мошенничестве
web_search "ИМЯ_ИСПОЛНИТЕЛЯ мошенник обман"
web_search "ИМЯ_ИСПОЛНИТЕЛЯ кидалово отзывы"
web_search "НОМЕР_ТЕЛЕФОНА мошенник услуги"
```

При обнаружении высокого риска — предупреди пользователя:

```
ВНИМАНИЕ: Обнаружены красные флаги!

Подрядчик: [Имя]
Площадка: [Название]

Красные флаги:
- [список обнаруженных признаков]

Рекомендация: НЕ НАНИМАТЬ без дополнительной проверки.
Если решите продолжить:
1. Не вносите предоплату более 30%
2. Оформите письменный договор
3. Зафиксируйте объём работ и сроки
4. Сделайте фото объекта до начала работ
```

## Обработка ошибок

| Проблема | Решение |
|----------|---------|
| CAPTCHA на Avito | Подожди 30-60 сек, обнови. Попроси пользователя пройти вручную в headed-режиме |
| Пустые результаты на площадке | Упрости запрос, попробуй другую формулировку, расширь географию |
| Страница не загружается | Увеличь sleep до 5-6 сек. Тяжёлые SPA. Проверь интернет. |
| Селекторы не работают | Сделай `browser-use state` для актуальной DOM-структуры. Селекторы меняются. |
| Модальное окно блокирует | Закрой через eval: `document.querySelector('[class*="close"]')?.click()` или Escape |
| Сессия зависла | `browser-use close --all`, начни заново |
| Цены не отображаются | Многие исполнители не указывают цену. Это нормально — укажи «Цена по запросу» |
| Дубликаты в результатах | Дедуплицируй по имени и номеру телефона. Объедини данные с разных площадок. |
| Профиль недоступен | Объявление может быть снято. Перейди к следующему результату. |
| Авторизация требуется | Попроси пользователя войти вручную в открытом браузере |
| Anti-bot на Avito | Минимизируй state-вызовы, делай паузы между действиями 3-5 сек |
| Яндекс.Услуги показывает мало результатов | Попробуй другую формулировку запроса или категорию напрямую |
| YouDo не загружает список | YouDo тяжёлый SPA — подожди 5 сек. Проверь через eval наличие элементов |
| Некорректные символы в URL | Кодируй кириллицу: `encodeURI('сантехник')` → `%D1%81%D0%B0%D0%BD%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D0%BA` |
| Element not found после навигации | DOM перерисовался — сделай state заново для свежих индексов |

## Оптимизация для повторных запросов

Если пользователь ищет несколько подрядчиков подряд:

1. **Не закрывай браузер** между поисками — переходи по новому URL
2. **Используй один профиль** для сохранения авторизации: `browser-use --profile "contractor-search"`
3. **Кешируй структуру DOM** — если площадка не обновлялась, селекторы те же
4. **Группируй запросы** — если 3+ категории, спрашивай «Искать все сразу или по очереди?»
5. **Сохраняй контекст** — предыдущие результаты могут помочь с дедупликацией

## Cleanup

```bash
# Закрыть текущую вкладку
browser-use close

# Закрыть ВСЕ сессии (использовать после завершения работы)
browser-use close --all
```
