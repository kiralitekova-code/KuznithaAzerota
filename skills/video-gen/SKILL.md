# Генерация видео

Создаём **готовое короткое видео** — «оживляем» фотографию (image-to-video) или генерируем ролик по текстовому описанию (text-to-video). Это закрывает запросы «оживить фото», «сделать видео», «нейросеть видео»: пользователь получает готовый видеофайл.

## Когда использовать

- «оживи фото / картинку» — image-to-video
- «сгенерируй видео / ролик по описанию» — text-to-video
- короткие ролики для постов, превью, заставки, анимация логотипа

## Когда НЕ использовать

- Монтаж, нарезка, склейка, субтитры для готовых видеофайлов — это не здесь.
- Длинные фильмы/лекции — модель делает короткие ролики (5–10 с).
- Картинка (статичная) — навык `image-studio`.

## Что на выходе

**Ссылка на готовый видеофайл** (после завершения рендера; переотданная, стабильная). До готовности — задача в статусе «обрабатывается».

## Важно: стоимость и время

- Генерация стоит **~0,20 $ за видео** (glm-фоллбэк) или **~0,40–0,60 $** (Kling, основной путь) — дорого. **Всегда** предупреждайте пользователя и уточняйте, действительно ли нужен именно ролик.
- Рендер занимает **1–5 минут**. Объясните пользователю, что результат будет не сразу.
- Результаты хранятся ~24 часа — отдавайте ссылку сразу и предлагайте скачать.

## Инструменты

| Задача | Инструмент |
|---|---|
| Отправить генерацию | MCP `kling_text_to_video` / `kling_image_to_video` по умолчанию (качество, звук; `task_id` сразу). Дешёвый фоллбэк — `glm_generate_video` |
| Дождаться результата | MCP `kling_get_generation` (Kling) / `glm_get_generation` (фоллбэк) — опрос статуса |
| Создать опорное изображение для i2v | MCP `kling_text_to_image` (фоллбэк — `glm_generate_image`), затем `analyze_image` для проверки |
| Сохранить | встроенные `write` |

Все MCP-инструменты серверные и кросс-платформенные. **Без bash/ffmpeg.**

## Рабочий процесс

### Шаг 1. Уточнить замысел (и предупредить о цене)

Что оживляем/снимаем, длительность, ориентация (горизонталь/вертикаль для Reels/Stories), нужен ли звук. **Обязательно скажите про стоимость и время ожидания.**

### Шаг 2. Собрать промпт и параметры

- **Промпт** (≤512 символов): что происходит, движение камеры, атмосфера. Конкретнее: «камера медленно наезжает, волосы развеваются на ветру, тёплый закатный свет».
- **Опорное изображение** (для «оживить фото»): путь/URL на картинку (PNG/JPEG ≤5 МБ). Нет картинки — можно сначала сделать её через `kling_text_to_image`.
- **Длительность**: 5–10 секунд (Kling — до 15).
- **Размер/ориентация**: горизонтальный (16:9) для YouTube/превью, вертикальный (9:16) для Reels/Stories.
- **Kling-параметры по умолчанию**: `resolution='720p'` и `audio='native'` (звук) — самый дешёвый вариант со звуком; 1080p/4K — только по явному запросу.
- **FPS** (glm-фоллбэк): 30 (дешевле/быстрее) или 60 (плавнее).
- **Качество** (glm-фоллбэк): speed (быстрее) или quality (лучше).

### Шаг 3. Отправить

Вызовите `kling_text_to_video` / `kling_image_to_video` (дешёвый фоллбэк — `glm_generate_video`) — инструмент сразу вернёт `task_id` (отправка не блокирует).

### Шаг 4. Опрос (дождаться результата)

Периодически вызывайте `kling_get_generation` / `glm_get_generation` (по использованному провайдеру):

- `PROCESSING` — ещё рендерится, подождите (~30–60 с) и повторите. **Не спамьте** запросами.
- `SUCCESS` — готово, вернётся URL видео. Отдайте его пользователю.
- `FAIL` — сообщите пользователю; предложите упростить промпт или другие параметры и повторить.

Можно использовать ключ идемпотентности, чтобы повторная отправка того же запроса не списывала средства дважды.

### Шаг 5. Доставка

Отдайте ссылку на видео и предложите скачать (хранение ~24 ч). Если результат не тот — скорректируйте промпт/длительность/опорное изображение и повторите (предупредив о цене).

## Антипаттерны

- **Не предупредили про цену и ожидание** → всегда говорите заранее.
- **Спам-опрос** статуса → раз в ~45–60 с, не чаще.
- **Слишком длинный/сложный замысел** для 5–10 секунд → упрощайте до одного движения/сцены.
- **Пытаетесь монтировать/склеивать** — это не сюда; здесь только генерация с нуля.
