# Подбор подарков — Gift Finder

Интеллектуальный подбор подарков с поиском на маркетплейсах **Wildberries** и **Ozon**. Анализ отзывов, сравнение цен, формирование персонализированного списка с прямыми ссылками.

## Обзор

Gift Finder — это навык подбора подарков, который сочетает аналитические способности LLM с реальными данными о товарах и ценах с крупнейших российских маркетплейсов.

| Маркетплейс | Доля рынка | Особенности |
|-------------|-----------|-------------|
| Wildberries | ~45% | Крупнейший маркетплейс РФ, быстрая доставка, огромный ассортимент |
| Ozon | ~30% | Широкий ассортимент, хорошие отзывы, premium-сегмент |

**Стратегия**: Генерация идей через LLM → Поиск на маркетплейсах → Анализ отзывов → Сравнение цен → Курированный список.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Сбор информации о получателе

Перед подбором подарка проведи интервью. Уточни:

### Обязательные вопросы

1. **Кому подарок?** — имя или кто этот человек (друг, мама, коллега, партнёр и т.д.)
2. **Повод** — день рождения, Новый год, 8 марта, 14 февраля, годовщина, повышение, 1 сентября, свадьба, юбилей, другое
3. **Возраст получателя** — до 18, 18-25, 25-35, 35-50, 50+
4. **Ваш бюджет** — конкретная сумма или диапазон

### Желательные вопросы (если пользователь готов рассказать)

5. **Пол получателя** — мужской / женский / не имеет значения
6. **Интересы и хобби** — спорт, кулинария, технологии, чтение, путешествия, музыка, игры, садоводство, мода, искусство
7. **Отношение к вам** — близкое, формальное, романтическое, семейное
8. **Что НЕ дарить** — аллергии, уже есть, не любит
9. **Формат подарка** — вещь, впечатление (сертификат), подписка, деньги в конверте
10. **Характер получателя** — практичный, сентиментальный, любит сюрпризы, консервативный

## Поводы и шаблоны подарков

### Дни рождения

Поиск персонализированного подарка на основе интересов. Фокус — на уникальности и соответствии личности.

### Новый год

Фокус — на тёплых, атмосферных подарках. Работают наборы, украшения, гаджеты для дома.

**Топ-категории**: свечи и ароматы, ёлочные игрушки, тёплые вещи, сладкие наборы, книги, подписки.

### 8 марта

Фокус — на заботе и внимании. Цветы + основной подарок — классика.

**Топ-категории**: уходовая косметика, ювелирные украшения, парфюм, сертификаты на SPA, книги, умные гаджеты.

### 14 февраля

Фокус — на романтике и личном отношении.

**Топ-категории**: ювелирные украшения, парфюм, романтические наборы, билеты (театр/концерт), фотокниги, personalized-подарки.

### 1 сентября

Фокус — на пользе для учёбы и мотивации.

**Топ-категории**: канцелярия (премиум), электронные книги, рюкзаки, наушники, наборы для творчества.

### Годовщина

Фокус — на символизме и воспоминаниях.

**Топ-категории**: ювелирные украшения с гравировкой, фотоальбомы, путёвки, персонализированные подарки.

### Повышение / новый этап

Фокус — на мотивации и новых возможностях.

**Топ-категории**: деловые аксессуары, гаджеты для продуктивности, книги по саморазвитию, подписки.

## Пошаговый рабочий процесс

### Шаг 1: Интервью

Проведи короткое интервью (см. раздел «Сбор информации»). Минимум 3-4 вопроса для адекватного подбора.

### Шаг 2: Генерация идей

На основе интервью сгенерируй 8-12 идей подарков. Используй знание LLM о трендах, категориях товаров и типичных предпочтениях.

Для каждой идеи укажи:
- **Название подарка**
- **Почему подходит** — привяжи к интересам/поводу
- **Примерная цена** — на основе бюджетной категории
- **Категория** — вещь/впечатление/подписка

### Шаг 3: Поиск на Wildberries

Открой Wildberries и ищи каждую подходящую идею.

#### URL-структура Wildberries

```
https://www.wildberries.ru/catalog/0/search.aspx?search=ЗАПРОС
```

**Параметры URL:**

| Параметр | Описание | Пример |
|-----------|----------|--------|
| `search` | Поисковый запрос (URL-encoded) | `беспроводные+наушники` |
| `sort` | Сортировка | `popular` (по популярности), `price升order` (по возрастанию цены), `priceorder` (по убыванию), `rate` (по рейтингу), `newly` (по новизне) |
| `page` | Страница | `1`, `2`, `3` |
| `priceU` | Фильтр цены (в копейках) | `minPrice_maxPrice` (напр. `500000_3000000` = 5 000 — 30 000 ₽) |
| `f21..26.value` | Фильтры (меняются) | Различные категории |

**Примеры URL:**

```
# Наушники, по рейтингу
https://www.wildberries.ru/catalog/0/search.aspx?search=беспроводные+наушники&sort=rate

# Книга, по популярности
https://www.wildberries.ru/catalog/0/search.aspx?search=книга+психология+бестселлер&sort=popular

# Ювелирное украшение до 5000₽
https://www.wildberries.ru/catalog/0/search.aspx?search=браслет+серебро&priceU=0_500000
```

#### Извлечение товаров Wildberries

```bash
browser-use close --all
node -e "new Promise(r=>setTimeout(r,1*1000)).then(process.exit)"
browser-use --headed open "https://www.wildberries.ru/catalog/0/search.aspx?search=ЗАПРОС&sort=rate"
node -e "new Promise(r=>setTimeout(r,5*1000)).then(process.exit)"
browser-use state
```

Обработай cookie-баннер:
```bash
browser-use click "text=Принять"
# или
browser-use click "text=Согласен"
node -e "new Promise(r=>setTimeout(r,1*1000)).then(process.exit)"
```

Извлечение данных о товарах:
```javascript
browser-use eval "
  const cards = document.querySelectorAll('[class*=\"product-card\"], [class*=\"ProductCard\"], article');
  const results = [];
  cards.forEach((card, i) => {
    if (i >= 10) return;
    const name = card.querySelector('[class*=\"goods-name\"], [class*=\"product-name\"], h3, [class*=\"brand\"]')?.textContent?.trim() || '';
    const price = card.querySelector('[class*=\"price\"], [class*=\"Price\"]')?.textContent?.trim() || '';
    const rating = card.querySelector('[class*=\"rating\"], [class*=\"stars\"]')?.textContent?.trim() || '';
    const reviews = card.querySelector('[class*=\"reviews\"], [class*=\"feedback\"]')?.textContent?.trim() || '';
    const link = card.querySelector('a[href*=\"/catalog/\"]')?.href || '';
    results.push({name, price, rating, reviews, link});
  });
  JSON.stringify(results);
"
```

### Шаг 4: Поиск на Ozon

#### URL-структура Ozon

```
https://www.ozon.ru/search/?text=ЗАПРОС
```

**Параметры URL:**

| Параметр | Описание | Пример |
|-----------|----------|--------|
| `text` | Поисковый запрос (URL-encoded) | `беспроводные+наушники` |
| `sorting` | Сортировка | `rating` (по рейтингу), `price` (по цене ↑), `price_desc` (по цене ↓), `new` (по новизне), `popularity` (по популярности) |
| `page` | Страница | `1`, `2` |
| `price_from` | Цена от (₽) | `1500` |
| `price_to` | Цена до (₽) | `5000` |
| `category` | Категория | ID категории |

**Примеры URL:**

```
# Наушники, по рейтингу
https://www.ozon.ru/search/?text=беспроводные+наушники&sorting=rating

# Книга
https://www.ozon.ru/search/?text=книга+психология&sorting=popularity

# Украшение, до 5000₽
https://www.ozon.ru/search/?text=браслет+серебро&price_to=5000&sorting=rating
```

### Шаг 5: Анализ отзывов

Для каждого товара из топ-5 открой страницу и проанализируй отзывы.

#### Wildberries — чтение отзывов

```bash
browser-use --headed open "ССЫЛКА_НА_ТОВАР"
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"
browser-use eval "
  // Прокрутить к отзывам
  const reviewsSection = document.querySelector('[class*=\"comments\"], [class*=\"reviews\"], [class*=\"feedback\"]');
  if (reviewsSection) reviewsSection.scrollIntoView();
  'scrolled';
"
node -e "new Promise(r=>setTimeout(r,2*1000)).then(process.exit)"
browser-use eval "
  const reviews = document.querySelectorAll('[class*=\"comment\"], [class*=\"review\"], [class*=\"feedback-item\"]');
  const results = [];
  reviews.forEach((r, i) => {
    if (i >= 10) return;
    const text = r.textContent?.trim() || '';
    const rating = r.querySelector('[class*=\"star\"], [class*=\"rating\"]')?.textContent?.trim() || '';
    results.push({rating, text: text.substring(0, 200)});
  });
  JSON.stringify(results);
"
```

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| Wildberries не загружает результаты | Закрой cookie-баннер. Подожди 5 сек. Используй `browser-use state` для анализа |
| Ozon показывает страницу входа | Wildberries и Ozon могут требовать авторизацию для поиска. Если просят — попроси пользователя залогиниться вручную |
| Нет результатов поиска | Упрости запрос. Используй более общие слова. Попробуй английское название |
| CAPTCHA | Подожди 30-60 сек. Попроси пользователя пройти вручную в headed-режиме |
| CSS-селекторы не работают | Селекторы маркетплейсов часто меняются. Используй `browser-use state` для анализа текущей структуры |
| Цены не отображаются | Возможно нужна авторизация или промедление при загрузке. Подожди 3-5 сек |
| Отзывы не загружаются | Прокрути к секции отзывов. Иногда нужно кликнуть на вкладку «Отзывы» |
| Модальное окно перекрывает контент | `browser-use keys "Escape"` или кликни вне модала |
| Товар закончился | Отметь это и предложи альтернативу |
| Медленная загрузка | Wildberries и Ozon — тяжёлые SPA. Подожди 5 сек после навигации |
| Некорректные символы в URL | Кодируй кириллицу и пробелы через URL encoding: `наушники` → `%D0%BD%D0%B0%D1%83%D1%88%D0%BD%D0%B8%D0%BA%D0%B8` |
| Браузер не открывается | Проверь `browser-use` установлен: `which browser-use`. При необходимости переустанови |
| Слишком много вариантов | Покажи топ-5 вместо полного списка. Предложи Top Pick с обоснованием |

## Советы по подбору подарков

### Золотые правила

1. **Слушай, а не предлагай** — чем больше знаешь о получателе, тем лучше подарок
2. **Опыт > Вещи** — исследования показывают, что впечатления приносят больше радости
3. **Практичность** — если человек практичный, дарить сувениры — плохая идея
4. **Личность, не бюджет** — дорогой, но «не в тему» подарок хуже дешёвого, но продуманного
5. **Упаковка** — красивая упаковка делает подарок лучше на 30%

### Красные флаги

- Пользователь хочет «что-нибудь» без контекста — уточни хотя бы 3 вопроса
- Бюджет не указан — предложи варианты в нескольких категориях
- Получатель — «начальник» — предложи нейтральные, профессиональные варианты
- Подарок «для двоих» — уточни, это подарок для пары или от пары

### Формат финального ответа

Всегда структурируй ответ:
1. **Top Pick** — лучший вариант с обоснованием
2. **Номерной список** — 5-7 вариантов с ценами и ссылками
3. **Альтернатива для каждого** — если основной вариант не подошёл
4. **Совет по подаче** — как упаковать/преподнести
5. **Текст для открытки** — если уместно
