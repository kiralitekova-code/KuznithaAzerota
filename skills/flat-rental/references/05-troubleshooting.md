## Troubleshooting

| Проблема | Решение |
|----------|---------|
| Cian показывает CAPTCHA | Подожди 30-60 секунд, обнови. Попроси пользователя пройти вручную в headed-режиме |
| Avito не загружает результаты | Закрой cookie-баннер. Проверь `browser-use state` на ошибки |
| Яндекс.Недвижимость показывает мало результатов | Это агрегатор — может быть меньше уникальных объявлений. Расширь фильтры |
| Пустые результаты на всех сайтах | Упрости запрос: расширь бюджет, убери фильтр района, попробуй +1 комнату |
| Не удаётся извлечь данные через eval | CSS-селекторы могут измениться. Используй `browser-use state` для анализа структуры страницы |
| Модальное окно перекрывает контент | `browser-use keys "Escape"` или кликни вне модала |
| Медленная загрузка | Cian и Avito — тяжёлые SPA. Подожди 4-5 сек после навигации |
| Некорректные символы в URL | Кодируй кириллицу через URL encoding |
| Дублируются объявления | Это нормально — агентства кросс-постят. Дедупликация на шаге 6 |
| Мошеннические объявления | Проверяй номер телефона через web_search, сверяй документы при просмотре |
| Браузер не открывается | Проверь `browser-use` установлен: `which browser-use`. При необходимости переустанови |
| Страница на английском | Добавь `/?lang=ru` к URL или используй `browser-use eval "document.cookie='lang=ru'"` |

## Типичные ошибки и предупреждения

**Предупреждения для пользователя:**

1. **Слишком низкая цена** — если цена на 30%+ ниже среднего по району, это подозрительно. Возможно мошенничество или скрытые проблемы.
2. **Нет просмотра** — никогда не переводите деньги без личного просмотра квартиры.
3. **Залог = 2+ месяца** — стандартный залог — 1 месяц. 2+ — признак жадного арендодателя.
4. **Просьба предоплаты** — никогда не платите до подписания договора и получения ключей.
5. **Только наличные** — предпочтительнее безналичная оплата с подтверждением перевода.
6. **Срочный выезд** — «срочно съезжаю, надо сдать за день» — возможная подстава.
