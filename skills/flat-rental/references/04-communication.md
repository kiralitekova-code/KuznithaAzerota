## Шаблоны общения с арендодателем

### Первичное сообщение

```
Здравствуйте! Видел ваше объявление о сдаче квартиры по адресу [адрес].
Хотел бы уточнить несколько вопросов:

1. Квартира ещё актуальна?
2. Каков размер залога / депозита?
3. Коммунальные включены в арендную плату или оплачиваются отдельно?
4. Какой минимальный срок аренды?
5. Можно ли зарегистрироваться (прописка временная)?
6. Есть ли какие-то ограничения (животные, курение, дети)?

Удобное время для просмотра: [предложить 2-3 варианта].
Спасибо!
```

### Вопросы перед просмотром

```
Спасибо за ответ! Перед просмотром хотел бы уточнить:

1. Какой этаж и есть ли лифт?
2. Тип дома (панельный, кирпичный, монолитный)?
3. Год постройки дома?
4. Соседи — кто живёт сверху и снизу?
5. Тихий двор / шумная улица?
6. Интернет — какой провайдер, скорость?
7. Были ли затопления?
8. Замена замков при заселении?
```

### Чек-лист для просмотра

```
## Что проверить при просмотре квартиры:

### Документы
- [ ] Паспорт собственника (сверить с документами на квартиру)
- [ ] Выписка из ЕГРН (свежая, до 30 дней)
- [ ] Согласие всех собственников (если несколько)
- [ ] Договор аренды — внимательно прочитать

### Состояние квартиры
- [ ] Вода — напор горячей и холодной (открыть краны)
- [ ] Канализация — нет ли запаха, скорость слива
- [ ] Отопление — батареи тёплые (в сезон), нет протечек
- [ ] Окна — открываются/закрываются, нет щелей
- [ ] Двери — замки работают, нет скрипов
- [ ] Электрика — розетки работают, нет искр
- [ ] Плита/духовка — работает
- [ ] Стиральная машина — включить тестовый режим
- [ ] Холодильник — морозит
- [ ] Телефонная связь и интернет

### Окрестности
- [ ] Шум с улицы (открыть окна)
- [ ] Шум от соседей (постоять тихо)
- [ ] Подъезд — чистота, освещение, лифт
- [ ] Парковка — есть ли места
- [ ] Соседи — познакомиться

### Финансы
- [ ] Точная сумма аренды
- [ ] Залог (размер, условия возврата)
- [ ] Коммунальные (что включено, примерная сумма)
- [ ] Счётчики — зафиксировать показания при заселении
- [ ] Способ оплаты (наличные, карта, перевод)
```

## Использование дополнительных инструментов

### web_search — для анализа рынка

Поиск средней арендной платы по району:
```
web_search("аренда [количество_комнат] [район] [город] средняя цена 2026")
```

Поиск отзывов о районе:
```
web_search("[район] [город] отзывы жильцов проживание")
```

Проверка арендодателя:
```
web_search("[телефон арендодателя] аренда мошенничество")
```

### web_reader — для чтения объявлений

Открой конкретное объявление для детального анализа:
```
web_reader("https://www.cian.ru/rent/flat/123456789/")
```
