# Workflow 3 — расшифровка анализов: полные детали

Читай перед выполнением Workflow 3 (шаги 1-3 и справочник частых анализов из SKILL.md).

## Шаг 1: Получение результатов

**Вариант A: Пользователь загрузил фото**
```
image_analysis(
  imageSource="URL фотографии",
  prompt="Распознай текст с медицинского анализа. Определи: название анализа, все показатели, их значения, единицы измерения и референсные диапазоны. Верни структурированный список."
)
```

**Вариант B: Пользователь написал текстом**
- Принять значения в свободном формате
- Попросить уточнить неполные данные

**Вариант C: Пользователь описал, что сдавал**
- Спроси конкретные показатели

## Шаг 2: Поиск референсных значений

Для каждого показателя, если референс не указан в результате:
```
web_search(
  query="{показатель} норма референсные значения анализ",
  count=3,
  freshness="noLimit",
  allowed_domains=["gemotest.ru", "invitro.ru", "citilab.ru"]
)
```

## Шаг 3: Анализ результатов

**Формат вывода:**
```
 Результаты анализов:

 Показатели в норме:
   - {Показатель}: {значение} {ед.} (норма: {от}-{до})  OK
   - ...

 Показатели вне нормы:
   - {Показатель}: {значение} {ед.} (норма: {от}-{до})  ВЫШЕ/НИЖЕ
   - ...

 Возможные причины отклонений:
   {Показатель}: {возможные причины — 1-2 предложения}

 На что обратить внимание у врача:
   - Обязательно скажи врачу про {показатель}
   - Спроси про {связанный показатель}
   - Возможно, потребуется пересдать через {срок}

 ВАЖНО: это не диагноз. Интерпретацию делает только врач
   с учётом твоей истории, симптомов и других анализов.
```
