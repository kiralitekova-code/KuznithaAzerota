# Writing Formats and Templates

Quick-reference for common writing formats. Use the appropriate structure when co-writing.

## Email Formats

### Business Email

```
[Hook: context for why you're writing — 1 sentence]
[Body: the ask or the information — 2-4 sentences]
[Call to action: what you need from them — 1 sentence]
```

Length: 3-6 sentences total. If longer, use bullet points.

### Follow-Up Email

```
[Reference: what you're following up on — 1 sentence]
[Status: where things stand — 1-2 sentences]
[Ask: what needs to happen next — 1 sentence]
```

### Difficult Email (delivering bad news, pushing back, declining)

```
[Acknowledge: show you understand their position — 1 sentence]
[Deliver: the news — direct, no burying — 1-2 sentences]
[Reason: why, without over-explaining — 1-2 sentences]
[Offer: what you can do instead, if anything — 1 sentence]
```

Never soften bad news with filler. Direct + brief reason = respectful.

## Hook Patterns

The opening line determines whether the rest gets read. Choose based on context:

| Hook Type | Best For | Example |
|-----------|----------|---------|
| **Direct statement** | Business, persuasive | "Your current approach will fail for one reason: it assumes users read instructions." |
| **Question** | Engaging, exploratory | "What would happen if we stopped treating productivity as a virtue?" |
| **Anecdote** | Personal, narrative | "Last Tuesday, I deleted my to-do list. It was the most productive thing I'd done all year." |
| **Surprising data** | Analytical, persuasive | "90% of what we call 'strategy' is actually just planning." |
| **Contrarian** | Opinion, thought leadership | "Meetings don't waste time. Bad meetings waste time. The solution isn't fewer meetings — it's better ones." |

## Tone Adaptation

When rewriting for a different tone, adjust these levers:

| Lever | Formal | Neutral | Casual |
|-------|--------|---------|--------|
| Sentence length | Longer, complex | Mixed | Shorter, punchy |
| Vocabulary | Precise, technical | Clear, standard | Colloquial |
| Contractions | None | Some | Full |
| First person | Avoid "I" | Mixed | Free "I" |
| Imperatives | "Please consider" | "Consider" | "Think about" |
| Hedging | "It may be beneficial" | "It might help" | "Try this" |

## Document Structures

### Blog Post / Article

```
Hook (1 paragraph)
  ↓ earns attention
Context (1-2 paragraphs)
  ↓ sets up the problem
Body (3-5 sections)
  ↓ develops the argument
  Each section: claim → evidence → implication
Synthesis (1 paragraph)
  ↓ connects back to hook
Close (1 paragraph)
  → next step or reflection
```

### Proposal / Pitch

```
Problem (1 paragraph)
  → why this matters now
Solution (1-2 paragraphs)
  → what you're proposing
Evidence (2-3 paragraphs)
  → why it will work
Risks + Mitigations (1 paragraph)
  → you've thought this through
Ask (1 paragraph)
  → what you need from the reader
```

### Short Message (Slack, Telegram, SMS)

One idea per message. If you need two ideas, send two messages.

- State the point in the first sentence
- Add context only if the receiver lacks it
- End with the action (if any), not context
