# Написание песен

Пишем **готовый текст песни** — куплеты, припев, бридж, с рифмой и ритмом, в заданном жанре и настроении. Закрывает запросы «написать песню», «придумать песню», «текст песни», «подбери рифму»: пользователь получает цельный текст, который можно исполнить или положить на музыку.

## Аудио — через MiniMax

Полный аудиотрек генерируется MCP-инструментами MiniMax:
- `minimax_generate_lyrics` ($0.01 за песню) — текст или доработка текста песни.
- `minimax_generate_music` ($0.15 за трек до 5 минут) — готовая песня целиком (вокал + аранжировка) из текста и описания стиля.

Правила: перед запуском `minimax_generate_music` предупреди о цене и получи согласие. Если пользователь ждёт «песню послушать» — предложи генерацию трека, не ограничивайся текстом. Сначала напиши текст этим навыком, затем передай его в инструмент генерации.

## Когда использовать

- «напиши / придумай песню» — с нуля по теме
- доработать, переписать или улучшить готовый текст
- подобрать рифмы, проверить ритм
- адаптировать текст под жанр, повод, аудиторию (детская, лирическая, танцевальная)
- сделать из текста готовый аудиотрек (через MiniMax выше)

## Когда НЕ использовать

- Тосты, стихи «в стол», сценки — ближе к `creative-thinking` / `writing-assistant`.
- Гимны для организаций с защищёнными авторскими правами — осторожно с заимствованиями.

## Что на выходе

1. **Полный текст песни** — куплеты + припев (+ бридж при необходимости).
2. **Структура** — пометки частей (Куплет 1 / Припев / Куплет 2 / Бридж / Припев / Аутро).
3. **Заметки** — темп/настроение, варианты исполнения, где подчеркнуть акцент.
4. **Аудиотрек** — если пользователь согласился: файл от `minimax_generate_music`.

## Рабочий процесс

### Шаг 1. Уточнить (по одному вопросу)

**Тема, жанр, настроение, повод, длина** (сколько куплетов), на каком языке. Для заказа/поздравления — кому и что важно сказать. Спросите также, нужен ли готовый аудиотрек или достаточно текста.

### Шаг 2. Выбрать структуру

- **Поп**: Куплет → Припев → Куплет → Припев → Бридж → Припев.
- **Рэп**: Интро → Куплеты (плотные, 16 строк) → Хук/Припев → Аутро.
- **Рок/Шансон**: Куплет → Припев → Куплет → Припев → Соло → Припев.
- **Детская**: короткие куплеты, простой припев-повторялка, считалочный ритм.
- **Лирическая баллада**: 2–3 куплета, припев-обращение, без бриджа.

### Шаг 3. Написать

- **Припев — ядро**: главная мысль и цепляющая фраза (hook), повторяется, легко запоминается.
- **Куплеты — развитие**: каждый продвигает сюжет или настроение к припеву.
- **Рифма**: парная (AABB), перекрёстная (ABAB), холостая (ABCB) — чередуйте для естественности; избегайте банальных рифм («любовь—кровь»).
- **Ритм (размер)**: держите ровное количество слогов в строках одной части — текст «ложится» на музыку.

### Шаг 4. Проверить и доработать

Прочитайте вслух — где спотыкается ритм, где рифма слабая, где штамп. Исправьте. Предложите 1–2 варианта ключевой строки на выбор.

### Шаг 5. Доставка

Отдайте текст с разметкой частей и краткой заметкой по настроению/темпу. Предложите доработать конкретные строки, сменить жанр или сгенерировать аудиотрек через MiniMax.

## Антипаттерны

- **Припев слабее куплетов** → припев — главное, ему максимум внимания.
- **Банальные/глагольные рифмы** в каждой строке → ищите свежие, чередуйте схемы.
- **Сбитый ритм** → считайте слоги, ровняйте строки внутри части.
- **Слишком буквально/«в лоб»** по теме → добавьте образ, деталь, конкретику — текст оживает.
- **Молчать про аудио** → если пользователь ждёт «песню послушать», предложите `minimax_generate_music` (с ценой и согласием), а не отговаривайтесь.
- **Генерировать трек без предупреждения о цене** → всегда предупреждайте и получайте согласие.
