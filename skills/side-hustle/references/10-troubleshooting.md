## Troubleshooting

| Проблема | Решение |
|----------|---------|
| Kwork требует авторизацию | Попроси пользователя войти в браузере, дождись подтверждения |
| CAPTCHA на FL.ru | Используй `--headed` режим, попроси пройти вручную |
| Мало заказов по специальности | Расширь запрос: смежные навыки, пересекающиеся технологии |
| Все заказы дешёвые | Попробуй FL.ru и Хабр Фриланс — средний чек выше |
| Заказчик не отвечает | Подожди 24-48 часов, отправь уточняющее сообщение |
| Подозрительный заказ | Проверь профиль заказчика: рейтинг, отзывы, дата регистрации |
| Результаты не загружаются | Подожди 3-5 сек, закрой cookie-баннер, обнови страницу |
| Модальное окно перекрывает контент | `browser-use press Escape` или кликни вне окна |
| Цены в валюте | Уточни у пользователя, в какой валюте оценивать |
| Нет портфолио | Предложи создать 2-3 демонстрационных проекта для портфолио |
