## Анализ района

Для каждого района в топ-10 выполни анализ инфраструктуры.

### Поиск информации о районе

```bash
# Используй web_search
web_search("[район] [город] инфраструктура школы парки магазины"
web_search("[район] [город] транспорт метро автобус"
web_search("[район] [город] безопасность криминал отзывы"
web_search("[район] [город] средняя арендная плата 2026"
```

### Чтение обзоров района

```bash
# Используй web_reader для подробных статей
web_reader("https://xn--80aesgpeag3bj.xn--p1ai/...")  # czytam.by/отзывы о районе
```

### Критерии оценки района

| Критерий | Вес | Как оценить |
|----------|-----|-------------|
| **Школы и детсады** | 20 | Количество в пешей доступности (до 1 км) |
| **Парки и зелёные зоны** | 15 | Ближайший парк/сквер, расстояние |
| **Метро / транспорт** | 25 | Расстояние пешком до метро, маршруты автобусов |
| **Магазины** | 15 | Супермаркеты в шаговой доступности (Пятёрочка, Перекрёсток, ВкусВилл) |
| **Безопасность** | 15 | Уровень преступности, освещение улиц |
| **Медицина** | 10 | Поликлиники, аптеки поблизости |

### Вывод анализа района

```
## Район: [Название]

**Общая оценка**: 7.5/10

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| Транспорт | 9/10 | Метро в 5 мин, 3 автобусных маршрута |
| Инфраструктура | 8/10 | Пятёрочка, Перекрёсток, аптека, почта |

| Школы | 8/10 | Школа №X в 7 мин, 2 детских сада |
```

## Анализ фотографий квартиры

Используй `image_analysis` для оценки фотографий каждого объявления.

### Процесс анализа

1. Открой страницу объявления через browser-use
2. Извлеки URL фотографий через eval
3. Для каждого фото вызови image_analysis

### Извлечение URL фото

```javascript
browser-use eval "
  const images = document.querySelectorAll('[class*=\"gallery\"] img, [class*=\"photo\"] img, [class*=\"image\"] img');
  const urls = [];
  images.forEach(img => {
    const src = img.src || img.dataset.src || '';
    if (src && !src.includes('avatar') && !src.includes('logo')) {
      urls.push(src);
    }
  });
  JSON.stringify(urls.slice(0, 10));
"
```

### Промпт для image_analysis

Для каждого фото отправляй:

> «Оцени качество этого фото квартиры. Проанализируй:
> 1. Качество естественного освещения — есть ли окна, насколько светло
> 2. Состояние ремонта — свежий/устаревший, качество материалов
> 3. Признаки проблем: трещины на стенах, пятна воды на потолке, плесень, обшарпанная мебель
> 4. Общее впечатление — приятное/нейтральное/неприятное
> 5. Реалистичность — похоже на фото реальной квартиры или стоковое/обработанное
> Оцени по шкале от 1 до 10.»

### Красные флаги на фото

| Признак | Что означает | Оценка |
|---------|-------------|--------|
| Пятна на потолке | Протечки, проблемы с крышей | -10 баллов |
| Трещины в стенах | Усадка дома, плохой ремонт | -5 баллов |
| Мало мебели | Возможно, реальная квартира не такая | -3 балла |
| Только общие планы | Скрывают детали, подозрительно | -5 баллов |
| Профессиональные фото | Часто агентство, реальность может отличаться | 0 баллов (нейтрально) |
| Стоковые фото | Мошенничество с вероятностью 80% | -15 баллов |
| Естественный свет, личные вещи | Реальная квартира, честный арендодатель | +5 баллов |
| Свежий ремонт, аккуратная мебель | Хороший вариант | +5 баллов |
