# image_analysis: промпты для документов и скриншотов

Читай, когда пользователь прислал фото справки 2-НДФЛ, договора или чека, а также для анализа скриншотов Госуслуг и ЛК ФНС.

## Использование image_analysis

### Фото справок 2-НДФЛ

Если пользователь прислал фото справки 2-НДФЛ:

```
image_analysis — prompt: «Распознай текст на этой справке 2-НДФЛ. Извлеки:
1. Работодателя (наименование, ИНН)
2. Доход за каждый месяц
3. Удержанный НДФЛ за каждый месяц
4. Общий доход и общий НДФЛ за год
5. Ставку налога»
```

На основе распознанных данных автоматически рассчитай возможный вычет.

### Фото договоров (купли-продажи, обучения, лечения)

```
image_analysis — prompt: «Распознай текст на этом договоре. Извлеки:
1. Тип договора (купля-продажа, оказание услуг, обучение, лечение)
2. Дата заключения
3. Стороны
4. Предмет договора
5. Сумма
6. Реквизиты (номер, дата)»
```

### Фото чеков и платёжных документов

```
image_analysis — prompt: «Распознай текст на этом чеке/платёжке. Извлеки:
1. Дата оплаты
2. Сумма
3. Наименование услуги/товара
4. Продавец/исполнитель»
```

### Скриншоты Госуслуг и ЛК ФНС

Если `browser-use eval` не может извлечь данные со страницы:

```bash
browser-use screenshot
```

Затем используй `image_analysis` для анализа скриншота — помогает проверить заполнение декларации, прочитать данные формы, обнаружить ошибки до отправки.
