## Troubleshooting

| Проблема | Решение |
|----------|---------|
| Auto.ru показывает CAPTCHA | Подожди 30-60 секунд, обнови. Попроси пользователя пройти вручную в headed-режиме |
| Avito блокирует или не загружает | Агрессивная антибот-защита. Минимизируй state, делай паузы 3-5 сек, только --headed |
| Drom.ru не отдаёт данные | Селекторы могут отличаться для мобильной и десктопной версии. Проверь через state |
| Пустые результаты на всех сайтах | Упрости запрос: расширь бюджет, убери фильтры, попробуй без модели (только марка) |
| Не удаётся извлечь данные через eval | CSS-селекторы могли измениться. Используй `browser-use state` для анализа структуры страницы |
| Модальное окно перекрывает контент | `browser-use keys "Escape"` или кликни вне модала |
| Медленная загрузка | Авто-площадки — тяжёлые SPA. Подожди 5-6 секунд после навигации |
| Некорректные символы в URL | Кодируй кириллицу через URL encoding |
| Дублируются объявления | Дилеры кросс-постят. Дедупликация на шаге 6 |
| VIN не находится в объявлении | Не все продавцы указывают VIN. Попроси продавца назвать по телефону |
| Фото не извлекаются | Некоторые площадки используют lazy-loading. Прокрути страницу перед извлечением: `browser-use eval "window.scrollTo(0, document.body.scrollHeight)"` |
| Браузер не открывается | Проверь `browser-use` установлен: `which browser-use`. При необходимости переустанови |
| Страница на английском | Добавь `/?lang=ru` к URL или используй `browser-use eval "document.cookie='lang=ru'"` |
| Цены в другой валюте | Все три площадки показывают цены в рублях. Другая валюта = баг парсинга |
