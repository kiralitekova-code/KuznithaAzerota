### Обзор платформы

Kwork.ru — крупнейшая российская биржа фриланса с моделью «магазин услуг» и биржей проектов. ~500 000 фрилансеров, ~50 000 активных заказов в месяц.

**Когда использовать**: Всегда начинай с Kwork — самая большая база заказов в РФ. Подходит для всех специальностей.

### Поиск проектов через browser-use

**URL-паттерн для биржи проектов:**

```
https://kwork.ru/projects?c={category_id}&q={query}&pi={page}
```

Параметры:
- `c` — ID категории (см. таблицу ниже)
- `q` — поисковый запрос (URL-encoded)
- `pi` — номер страницы (начиная с 1)
- `price_from` — минимальная цена
- `price_to` — максимальная цена

**Категории Kwork:**

| ID | Категория | Примеры заказов |
|----|-----------|----------------|
| 1 | Тексты и переводы | Статьи, копирайтинг, переводы, редактура |
| 2 | Графика и дизайн | Логотипы, баннеры, иллюстрации, UI/UX |
| 3 | Разработка и IT | Сайты, приложения, скрипты, боты |
| 4 | Аудио и видео | Монтаж, озвучка, субтитры, анимация |
| 5 | SEO и трафик | Продвижение, ссылки, аудит |
| 6 | Бизнес и жизнь | Консультации, бизнес-планы, презентации |
| 7 | Маркетинг и реклама | Таргет, контекст, SMM, email |
| 8 | Соцсети | Подписчики, лайки, комменты, ведение |
| 9 | Программирование | Python, JS, 1C, парсинг, боты |

### Примеры URL для поиска

| Запрос | URL |
|--------|-----|
| Все проекты по дизайну | `https://kwork.ru/projects?c=2` |
| Python-разработка | `https://kwork.ru/projects?c=9&q=python` |
| Копирайтинг от 3000 руб | `https://kwork.ru/projects?c=1&price_from=3000` |
| Сайты на WordPress | `https://kwork.ru/projects?c=3&q=wordpress` |
| Монтаж видео | `https://kwork.ru/projects?c=4&q=монтаж+видео` |

### Пошаговая навигация

```bash
# Открой список проектов
browser-use --headed open "https://kwork.ru/projects?c=9&q=python"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use state
```

### Извлечение результатов

Из каждой карточки проекта извлеки:

| Поле | Описание | Пример |
|------|----------|--------|
| Название | Заголовок проекта | «Нужен Telegram-бот на Python» |
| Описание | Текст описания заказа | Требования, сроки, детали |
| Бюджет | Цена заказа | «3 000 - 5 000 ₽» или «до 10 000 ₽» |
| Срок | Дедлайн | «3 дня», «неделя», «не указан» |
| Заказчик | Ник и рейтинг | «ivanov_a» ★ 4.8 (12 отзывов) |
| Количество откликов | Сколько уже откликнулись | «5 откликов» |
| Дата публикации | Когда размещён | «2 часа назад», «сегодня» |
| Ссылка | URL проекта | `/projects/123456/...` |

**Важно**: CSS-классы на Kwork динамические. Не привязывайся к конкретным селекторам — используй текстовое содержимое и структуру.

### Страница конкретного проекта

```bash
browser-use --headed open "https://kwork.ru/projects/123456/description"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use state
```

На странице проекта извлеки дополнительно:
- Полное описание задачи
- Вложения (скриншоты, ТЗ, референсы)
- Вопросы от других фрилансеров
- Требования к исполнителю (рейтинг, отзывы, статус)
