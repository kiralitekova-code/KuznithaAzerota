# Налоговый навигатор

Помощь с налоговыми вычетами и декларированием доходов в России. Навигация по Госуслугам через browser-use, поиск актуальных правил в НК РФ через web_search и web_reader.

## Важно

Данный навык предоставляет **информацию общего характера, а не налоговую или юридическую консультацию**. Я — искусственный интеллект, а не налоговый консультант. Налоговое законодательство и практика его применения меняются. Перед принятием решений проконсультируйтесь с лицензированным специалистом. Ответственность за достоверность подаваемых деклараций несёт налогоплательщик.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Рабочий процесс

### Шаг 1. Интервью с пользователем

Задай следующие вопросы (адаптируй под контекст):

1. **Доход**: Какой у вас доход за год? Какой вид дохода? (зарплата, ИП, ГПХ, аренда)
2. **Жильё**: Покупали ли вы жильё в последние 3 года? Была ли ипотека?
3. **Лечение**: Тратились ли на лечение (свое или родственников)? Сумма? Было ли дорогостоящее?
4. **Обучение**: Оплачивали обучение (свое или детей)? Сумма? Форма обучения?
5. **Дети**: Есть ли несовершеннолетние дети? Дети-инвалиды? Дети на очном обучении (18-24)?
6. **Инвестиции**: Есть ли ИИС? Какой тип (А или Б)? Сумма взноса за год?
7. **Статус**: Вы ИП, самозанятый, или работаете по трудовому договору?
8. **Вычеты ранее**: Получали ли вы налоговые вычеты раньше? Какие?

Если пользователь прислал фото справки 2-НДФЛ, договора или чека — готовые промпты для `image_analysis` — в `references/03-image-analysis.md`.

### Шаг 2. Определение применимых вычетов

На основе ответов:
1. Отметь все применимые типы вычетов
2. Рассчитай примерную сумму каждого вычета
3. Покажи пользователю итоговую таблицу:

```
| Тип вычета | Основание | Сумма к возврату |
|-----------|-----------|-----------------|
| Имущественный | ст. 220 | 260 000 руб. |
| Социальный (лечение) | ст. 219 | 15 600 руб. |
| Стандартный (дети) | ст. 218 | 3 770 руб. |
| **Итого** | | **279 370 руб.** |
```

Полные карточки всех 5 типов вычетов (основания, лимиты, условия, расчёты, документы) — в `references/01-deductions.md`.
Дерево решений «какие вычеты применяются» — там же, в конце файла.

### Шаг 3. Расчёт сумм

Для каждого вычета покажи формулу расчёта:

```
Имущественный вычет:
  Стоимость квартиры: 5 000 000 руб.
  Максимум для вычета: 2 000 000 руб.
  Сумма вычета: 2 000 000 * 13% = 260 000 руб.
  НДФЛ удержанный за год: 780 000 * 13% = 101 400 руб.
  К возврату за этот год: 101 400 руб.
  Остаток на следующие годы: 260 000 - 101 400 = 158 600 руб.
```

Формулы расчёта для всех типов вычетов — в `references/01-deductions.md` (секция «Расчётные формулы»).

### Шаг 4. Формирование чек-листа документов

Для каждого типа вычета выведи список документов (см. секции выше). Отметь:
- Документы, которые есть у пользователя
- Документы, которые нужно получить
- Где и как получить недостающие документы

Полные списки документов по каждому типу вычета — в `references/01-deductions.md`.

### Шаг 5. Подача через Госуслуги

Полная процедура подачи 3-НДФЛ (открытие формы, заполнение, отправка), URL-паттерны Госуслуг, проверка авторизации, закрытие баннеров и модалок — в `references/02-gosuslugi.md`.
Промпты для анализа скриншотов Госуслуг и ЛК ФНС через `image_analysis` — в `references/03-image-analysis.md`.

### Шаг 6. Отслеживание статуса

```bash
# Открыть историю поданных деклараций
browser-use open "https://www.gosuslugi.ru/10042/1"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"

# Получить статус последней декларации
browser-use state
```

Статусы декларации:
1. «Зарегистрирована» — получена ФНС
2. «На проверке» — камеральная проверка (до 3 месяцев)
3. «Проверка завершена» — решение принято
4. «Возврат одобрен» — деньги будут перечислены
5. «Доначислено» — требуются доплаты (проверь обоснованность)

**Камеральная проверка**: до 3 месяцев (ст. 88 НК РФ). Перечисление денег — в течение 1 месяца после окончания проверки (ст. 78 НК РФ).

## Типичные ошибки

1. **Пропуск срока давности** — вычет можно получить за последние 3 года. Декларации старше 3 лет ФНС не принимает.
2. **Неполный пакет документов** — самая частая причина отказа. Проверь чек-лист дважды.
3. **Путаница с дорогостоящим лечованием** — если код услуги «2» в справке, лимит не применяется. Код «1» — входит в 120 000 руб.
4. **Забыли про ипотечные проценты** — это отдельный вычет (до 390 000 руб.), его часто не заявляют.
5. **Вычет с материнского капитала** — сумма МК не учитывается в расходах на жильё.
6. **Двойной вычет супругов** — каждый супруг имеет право на вычет с 2 000 000 руб. (при стоимости от 4 000 000 руб.).
7. **Неправильный год возникновения права** — при ДДУ право возникает в год акта приёма-передачи, а не оплаты.
8. **Получение через работодателя и ФНС одновременно** — за один и тот же период нельзя. Выбери один способ.
9. **Нет дохода, облагаемого НДФЛ** — без дохода (безработный, ИП на УСН) вычет не получить. Перенести на будущие периоды можно.
10. **ИИС закрыт раньше 3 лет** — все полученные вычеты типа А придётся вернуть.

## Использование web_search и web_reader

Для получения актуальной информации:

```bash
# Поиск актуальных ставок и правил
web_search "налоговый вычет 2026 имущественный изменения НК РФ ст 220"

# Проверка сроков подачи
web_search "срок подачи 3-НДФЛ 2026 налоговая декларация"

# Чтение страницы ФНС
web_reader "https://www.nalog.gov.ru/rn77/individuals/property/nalog_deduction/"

# Проверка перечня дорогостоящего лечения
web_search "перечень дорогостоящего лечения налоговый вычет 2026 код услуги 2"
```
