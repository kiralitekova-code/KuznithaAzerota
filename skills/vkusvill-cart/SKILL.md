# Корзина ВкусВилл — browser-use

Автоматизируем добавление товаров в корзину на [vkusvill.ru](https://vkusvill.ru) через `browser-use` CLI. Каждое действие — через реальный браузер: открываем страницы, ищем товары, добавляем в корзину.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Требования (после установки)

- `browser-use` CLI установлен и доступен на PATH
- Аккаунт на vkusvill.ru (телефон + пароль или авторизация через соцсети)
- Для headed режима: дисплей или X11 forwarding

## Проверка перед работой

**ВЫПОЛНЯЙ ПЕРЕД КАЖДЫМ СЕАНСОМ.** Это предотвращает 90% проблем.

```bash
# 1. Закрыть все старые сессии
browser-use close --all
node -e "new Promise(r=>setTimeout(r,1*1000)).then(process.exit)"

# 2. Открыть ВкусВилл в headed режиме
browser-use --headed open https://vkusvill.ru
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"

# 3. Проверить состояние страницы
browser-use state
```

Что проверять в `state` (баннер cookies, авторизация, адрес, промо-модалки) и как реагировать — в `references/01-preflight-address.md`; читай его перед началом сессии.

## Авторизация

Если пользователь не авторизован, нужно попросить его войти вручную. Автоматизировать вход нельзя — это небезопасно и ненадёжно.

**Попроси пользователя:**
> «Чтобы добавить товары в корзину, нужно войти в аккаунт ВкусВилл. Пожалуйста, авторизуйся в открывшемся окне браузера, а потом напиши "готово".»

**Альтернатива — профиль браузера для сохранения сессии:**
```bash
browser-use --profile "vv" --headed open https://vkusvill.ru
```
При первом запуске пользователь авторизуется. При последующих — сессия сохраняется.

**Проверка после авторизации пользователем:**
```bash
browser-use state
# Подождать и проверить снова
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use eval "!!document.querySelector('[class*=\"user\"], [class*=\"profile\"], [class*=\"account\"], .HeaderUser')"
```

## Установка адреса доставки

**Адрес ОБЯЗАТЕЛЕН для добавления товаров в корзину.** Без него кнопка «В корзину» может не работать или товары добавятся в «отложенные».
Пошаговая установка адреса (кнопка в шапке → «Добавить новый адрес» → ввод адреса → подсказка из списка → подтверждение → выбор времени доставки; если адрес не устанавливается — вне зоны доставки) — в `references/01-preflight-address.md`.

## Добавление товара в корзину

Для каждого товара из списка (полные bash-команды и установка количества — в `references/03-add-to-cart.md`):

1. Открой `https://vkusvill.ru/search/?q=<название_товара>`, подожди 3 с.
2. Закрой модалки, если появились.
3. Проверь, что товары загрузились (количество карточек > 0); если 0 — товар не найден, попробуй другой запрос.
4. Прочитай первый товар: название, цена, вес/объём.
5. Получи `state`, найди индекс кнопки «В корзину», кликни её, подожди 1 с.
6. Если нужно количество > 1 — установи количество: весовой товар (кг) или штучный (шт) — процедура в `references/03-add-to-cart.md`.

## Весовые товары: продвинутые тактики

На vkusvill.ru весовые товары добавляются с дефолтным весом (обычно 0.85 кг). Контрол количества часто реализован как `<span>`, а не `<input>` — стандартный `browser-use type` не работает. Минус-кнопка может сбрасывать товар в 0 вместо уменьшения.

Пробуй тактики **по порядку** — переходи к следующей, если предыдущая не сработала:
Все 4 тактики (React-стейт через `__REACT_INTERNALS__`, клик на `<span>` с весом, кнопки «+»/«−» с проверкой шага, fallback с корректировками), определение фасовки и стратегия поиска — в `references/04-weight-tactics.md`.

## Batch add mode (для списков 10+ товаров)
Когда нужно добавить много товаров (20+), поштучный search → state → click занимает 15-20 минут. Batch mode сокращает время в 3-4 раза.
Полная процедура (разделение штучные/весовые, batch-добавление через eval, проверка корзины) — в `references/05-batch-verify.md`.

## Чекпоинты при добавлении в корзину
При добавлении 10+ товаров сохраняй прогресс каждые 10 позиций.
Формат файла `cart-progress.md`, когда сохранять, старт сессии и завершение — в `references/06-checkpoints-share.md`.

## Полный workflow: добавление списка товаров

```bash
# === PRE-FLIGHT ===
browser-use close --all
node -e "new Promise(r=>setTimeout(r,1*1000)).then(process.exit)"
browser-use --headed open https://vkusvill.ru
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"

# Проверить авторизацию
browser-use eval "!!document.querySelector('[class*=\"user\"], [class*=\"profile\"], [class*=\"account\"], .HeaderUser')"
# Если false → ПОПРОСИТЬ ПОЛЬЗОВАТЕЛЯ АВТОРИЗОВАТЬСЯ

# Закрыть модалки
browser-use eval "document.querySelector('[class*=\"modal\"], [class*=\"popup\"]')?.querySelector('[class*=\"close\"], [aria-label=\"Закрыть\"]')?.click()"

# Проверить адрес
browser-use eval "document.querySelector('[class*=\"address\"], [class*=\"AddressButton\"]')?.textContent?.trim()?.length > 3"
# Если false → УСТАНОВИТЬ АДРЕС

# === ПРОВЕРИТЬ ЧЕКПОИНТ ===
# Если есть cart-progress.md со status: in_progress → предложить продолжить

# === BATCH: ШТУЧНЫЕ ТОВАРЫ ===
# Для каждого штучного товара (без state на каждой странице):
browser-use open "https://vkusvill.ru/search/?q=<товар>"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use eval "document.querySelector('[class*=\"modal\"], [class*=\"popup\"]')?.querySelector('[class*=\"close\"]')?.click()"
browser-use eval "document.querySelectorAll('[class*=\"product-card\"]').length"  # > 0?
browser-use eval "document.querySelector('[class*=\"add-to-cart\"], [class*=\"AddButton\"]')?.click() || 'no_btn'"
node -e "new Promise(r=>setTimeout(r,1*1000)).then(process.exit)"
# НЕ делать state! Только eval для проверки

# ЧЕКПОИНТ каждые 10 товаров

# === ВЕСОВЫЕ ТОВАРЫ (отдельно, после батча) ===
# Для каждого весового товара — полный алгоритм с тактиками из секции выше

# === VERIFY CART ===
browser-use open "https://vkusvill.ru/cart/"
node -e "new Promise(r=>setTimeout(r,3*1000)).then(process.exit)"
browser-use eval "document.querySelectorAll('.ProductCard, .cart-item, [class*=\"basket-product\"]').length"

# === SHARE LINK ===
# (см. секцию «Получение ссылки на корзину» с обработкой truncation)
```

Детали: проверка корзины (содержимое + итог) — `references/05-batch-verify.md`; чекпоинты и получение ссылки на корзину с обработкой truncation — `references/06-checkpoints-share.md`.

## Обработка ошибок

| Проблема | Решение |
|----------|---------|
| Товар не найден (0 карточек) | Упрости запрос. Попробуй синоним. Сообщи пользователю. |
| Модалка блокирует действия | `eval` чтобы кликнуть close. Или Escape. |
| Кнопка «В корзину» не нажимается | Проверь адрес доставки — без адреса кнопка может не работать |
| Количество не вводится | Попробуй кнопку «+». Если и она не работает — товар может быть unavailable |
| Корзина пустая после добавления | Проверь авторизацию. Без логина корзина не сохраняется. |
| Ссылка «Поделиться» не найдена | Верни URL корзины. Ссылка может быть недоступна в некоторых регионах. |
| Страница долго грузится | Увеличь sleep до 5 секунд. VkusVill — тяжёлый SPA. |
| «Element not found» после навигации | DOM перерисовался — запусти `state` заново для свежих индексов. |
| Сессия зависла | `browser-use close --all`, начни заново. |
| Неверный товар добавлен | Перейди в корзину, удали (кнопка «−» до 0 или «Удалить»), и повтори поиск с уточнённым запросом. |

## Оптимизация: не злоупотребляй state

`browser-use state` дампит весь DOM. VkusVill SPA рендерит 5000+ px — state тормозит 10-30 секунд и забивает контекст.
Правила (когда делать `state`, а когда `eval`) и быстрые eval-сниппеты для типовых проверок — в `references/07-snippets.md`.

## Советы

1. **Всегда `close --all` первым** — устаревшие сессии — причина #1 зависаний.
2. **Жди после навигации** — VkusVill — тяжёлый SPA. `sleep 3-4` после `open`.
3. **Проверяй модалки перед каждым действием** — они появляются непредсказуемо.
4. **Не переиспользуй индексы** — после любого действия DOM меняется, делай `state` заново.
5. **Адрес — обязателен** — без адреса корзина работает некорректно.
6. **Авторизация — обязательна** — без логина товары не сохраняются.
7. **Упрощай запросы** — «Филе куриной грудки ВкусВилл» → «куриная грудка».
8. **Проверяй корзину в конце** — убедись что все товары добавлены.
9. **Используй `--profile`** — для сохранения сессии между запусками: `browser-use --profile "vv" --headed open https://vkusvill.ru`
