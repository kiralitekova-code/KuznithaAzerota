# Поиск квартиры в аренду — Flat Rental Navigator

Поиск квартиры в аренду одновременно на трёх крупнейших площадках России: **Cian**, **Avito** и **Яндекс.Недвижимость**. Дедупликация, анализ цен, оценка районов и фото, помощь в общении с арендодателями.

## Обзор

Три платформы покрывают ~90% рынка аренды жилья в России:

| Платформа | Доля рынка | Особенности |
|-----------|-----------|-------------|
| Cian | ~35% | Специализированный недвижимость-сайт, подробные фильтры, больше данных от агентств |
| Avito | ~40% | Крупнейший классифайд, много объявлений от собственников, но много дублей |
| Яндекс.Недвижимость | ~15% | Агрегатор, тянет данные с других площадок, удобные карты |

**Стратегия**: Параллельный поиск по всем трём платформам с последующей дедупликацией и ранжированием.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Сбор требований у пользователя

Перед поиском уточни у пользователя:

1. **Город** — Москва, Санкт-Петербург, другой
2. **Район / станция метро** — конкретные районы или общая зона
3. **Бюджет** — минимальная и максимальная арендная плата в месяц (₽)
4. **Количество комнат** — студия, 1, 2, 3+
5. **Срок аренды** — длительная / посуточно
6. **Тип жилья** — квартира, апартаменты, комната
7. **Этаж** — предпочтения по этажу (не первый, не последний и т.д.)
8. **Метраж** — минимальная площадь
9. **Ремонт** — любой, косметический, дизайнерский
10. **Дополнительно** — с мебелью, с животными, лифт, парковка, балкон
11. **Кто сдаёт** — от собственника / от агентства / без разницы

## Пошаговый рабочий процесс

Опроси пользователя (см. раздел «Сбор требований»). Если пользователь указал не все параметры — уточни недостающие или используй разумные значения по умолчанию.

Для каждой платформы последовательно. Базовые команды (закрытие сессий, открытие сайта, ожидание, проверка состояния) — в `references/02-extraction.md`.

- Продолжи после

### Шаг 4: Извлечение объявлений

Используй JavaScript `eval` для извлечения данных из каждого сайта.

Готовые JS-сниппеты для Cian, Avito и Яндекс.Недвижимость — в `references/02-extraction.md`.

### Шаг 5: Пагинация

Если результатов много, переходи на следующую страницу — команды для Cian, Avito и Яндекса в `references/02-extraction.md`. Собирай объявления с 2-3 страниц с каждой платформы. Обычно этого достаточно для хорошего покрытия.

### Шаг 6: Дедупликация

После сбора всех объявлений с трёх платформ выполни дедупликацию:

**Признаки дубликатов:**
- Одинаковый адрес (улица + дом)
- Одинаковая цена ±5%
- Одинаковая площадь ±2 м²
- Одинаковые фото (визуально похожие)
- Кросс-постинг: агентство размещает на всех площадках

**Алгоритм дедупликации:**
1. Группируй по адресу
2. Внутри группы — сравни цену и площадь
3. Если совпадают — оставь объявление с максимальной информацией (обычно Cian)
4. Отметь источник: «найдено на Cian, Avito, Яндекс»

### Шаг 7: Скоринг и ранжирование

#### Алгоритм скоринга

Каждое объявление получает оценку от 0 до 100 баллов:

| Критерий | Вес | Баллы | Описание |
|----------|-----|-------|----------|
| **Цена/м²** | 30 | 0-30 | Сравнение со средней ценой по району. Ниже среднего = больше баллов |
| **Транспорт** | 20 | 0-20 | Близость к метро (0-5 мин = 20, 5-10 = 15, 10-15 = 10, 15+ = 5) |
| **Качество фото** | 15 | 0-15 | Оценка через image_analysis (см. ниже) |
| **Свежесть** | 15 | 0-15 | Сегодня = 15, вчера = 12, 2-3 дня = 8, неделя = 4, старше = 1 |
| **Район** | 10 | 0-10 | Оценка инфраструктуры района (см. ниже) |
| **Полнота описания** | 5 | 0-5 | Подробное описание = больше баллов |
| **Рейтинг арендодателя** | 5 | 0-5 | Проверенный собственник / агентство с отзывами |

#### Расчёт цены за м²

```
цена_за_м2 = цена_аренды / площадь
средняя_цена_район = median([цена_за_м2 для всех объявлений в районе])

если цена_за_м2 <= средняя * 0.8 → 30 баллов (отличная цена)
если цена_за_м2 <= средняя * 0.9 → 25 баллов (хорошая цена)
если цена_за_м2 <= средняя * 1.0 → 20 баллов (средняя цена)
если цена_за_м2 <= средняя * 1.1 → 10 баллов (выше среднего)
если цена_за_м2 > средняя * 1.1 → 5 баллов (дорого)
```
