# Workflow 1 — поиск врача: полные детали

Читай перед выполнением Workflow 1 (шаги 1-4 и справочник специальностей из SKILL.md).

## Шаг 1: Уточнение запроса

Спроси пользователя:
1. **Какой специалист нужен?** — если не знает, спроси про симптомы и предложи подходящего врача
2. **Город / район** — где удобнее принять
3. **Государственная или частная клиника** — ОМС или платно
4. **Бюджет** (если платно) — примерный диапазон
5. **Удобное время** — будни / выходные, утро / вечер

## Шаг 2: Поиск на ProDoctorov

```
web_search(
  query="врач {специальность} {город} отзывы рейтинг prodoktorov",
  count=10,
  freshness="noLimit",
  allowed_domains=["prodoctorov.ru"]
)
```

**Если результатов мало:**
```
web_search(
  query="врач {специальность} {город} отзывы",
  count=10,
  freshness="noLimit"
)
```

## Шаг 3: Чтение профилей

Для каждого подходящего результата:
```
web_reader(url="URL профиля врача", return_format="text")
```

**Извлечь из профиля:**
- ФИО и звание/категория
- Стаж работы
- Специализация
- Место приёма (клиника, адрес)
- Стоимость приёма
- Рейтинг и количество отзывов
- Ключевые отзывы (последние 3-5)

## Шаг 4: Сравнение и рекомендация

**Формат вывода (топ-3 врача):**
```
 Рекомендую лучших {специальность} в {город}:

 1. {ФИО}, {категория}
    Стаж: {N} лет | Рейтинг: {X.X}/5 ({M} отзывов)
    Клиника: {название}, {адрес}
    Стоимость приёма: {цена} ₽
    Сильные стороны: {из отзывов}
    Записаться: {ссылка}

 2. {ФИО}, {категория}
    ...

 3. {ФИО}, {категория}
    ...

 Мой совет: врач №{N} лучше всего подходит, потому что {причина}.
```

## Справочник специальностей

Если пользователь не знает, к какому врачу идти:

| Симптомы | Рекомендуемый врач |
|----------|-------------------|
| Боль в животе, изжога, тошнота | Гастроэнтеролог |
| Головная боль, головокружение, онемение | Невролог |
| Боль в суставах, спине, отёки | Ревматолог / Ортопед |
| Кашель, одышка, боль в груди | Терапевт → Пульмонолог |
| Высыпания на коже, зуд | Дерматолог |
| Усталость, набор веса, потливость | Эндокринолог |
| Тревожность, бессонница, апатия | Психотерапевт / Психиатр |
| Нарушения мочеиспускания, боли в пояснице | Уролог / Нефролог |
| Боль в сердце, аритмия, одышка при нагрузке | Кардиолог |
| Проблемы со зрением | Офтальмолог |

**Правило:** при сомнениях всегда рекомендуй начать с терапевта — он направит дальше.
