# Поиск подработок и фриланса

Помогаю найти подработку или фриланс-заказы под твои навыки. Сканирую основные российские биржи фриланса, оцениваю релевантность и помогаю с откликами.

## Установка browser-use

Для работы навыка нужен `browser-use` CLI — это Python-пакет, поэтому **Python должен быть установлен**.
На Windows Python есть не всегда; на macOS/Linux — как правило, есть.

**Прежде чем что-либо устанавливать — скажи пользователю и получи подтверждение.**
Не устанавливай Python и пакеты молча и по умолчанию не запускай системные установщики
(`winget`/`brew`/`apt`/`curl`) без явного согласия.

Порядок действий:
1. Проверь: `browser-use --version`. Если команда есть — навык готов к работе.
2. Если `browser-use` не установлен — объясни пользователю, что нужен Python и пакет
   `browser-use`, и спроси разрешение установить: `pip install browser-use && browser-use install`.
   На Windows при отсутствии Python предложи скачать установщик с python.org
   (обязательно с галочкой «Add Python to PATH»), затем повторить `pip install`.
3. Если установка не удалась или пользователь отказался — не зацикливайся: честно сообщи,
   что автоматизация браузера сейчас недоступна, и предложи выполнить задачу вручную по шагам.

Не скрывай от пользователя команды и ошибки.

## Шаг 0: Интервью с пользователем

Перед поиском заказов обязательно спроси:

1. **Навыки и стек** — что умеешь (дизайн, разработка, копирайтинг, маркетинг, перевод, видео, аналитика, другое)
2. **Опыт** — новичок / есть портфолио / опытный фрилансер
3. **Желаемый доход** — в час / в месяц / за заказ
4. **Формат** — разовые заказы, долгосрочные проекты, почасовая работа
5. **Время** — сколько часов в неделю можешь уделять
6. **Готовность** — готов(а) начать сразу / нужна неделя на подготовку
7. **Портфолио** — есть ли работы для показа (ссылки)
8. **Предпочтения** — какие биржи уже используешь, что не нравится
9. **География** — работаешь с заказчиками из РФ только / СНГ / весь мир

Если пользователь уже описал свою ситуацию в чате — не задавай все вопросы, уточни только недостающее.

## Workflow 1: Kwork.ru — основная биржа фриланса

**Обзор платформы** — Kwork.ru: крупнейшая российская биржа фриланса с моделью «магазин услуг» и биржей проектов (~500 000 фрилансеров, ~50 000 активных заказов в месяц). **Когда использовать: всегда начинай с Kwork** — самая большая база заказов в РФ, подходит для всех специальностей.
**Поиск проектов через browser-use** — URL-паттерн `https://kwork.ru/projects?c={category_id}&q={query}&pi={page}`, параметры (`c`, `q`, `pi`, `price_from`, `price_to`) и таблица категорий Kwork (ID 1-9) — в `references/01-kwork.md`.
**Примеры URL для поиска** — готовые запросы (дизайн, Python, копирайтинг от 3000 ₽, WordPress, монтаж видео) — в `references/01-kwork.md`.
**Пошаговая навигация** — открой список проектов: `browser-use --headed open "URL"`, пауза 3 сек, `browser-use state`.
**Извлечение результатов** — из каждой карточки проекта извлеки: название, описание, бюджет, срок, заказчика (ник и рейтинг), количество откликов, дату публикации, ссылку. CSS-классы Kwork динамические — не привязывайся к конкретным селекторам, используй текстовое содержимое. Полная таблица полей — в `references/01-kwork.md`.
**Страница конкретного проекта** — открой `https://kwork.ru/projects/{id}/description`, извлеки полное описание задачи, вложения, вопросы от фрилансеров и требования к исполнителю — в `references/01-kwork.md`.

## Workflow 2: FL.ru — биржа фриланса

**Обзор платформы** — FL.ru: одна из старейших бирж фриланса в рунете, проектная модель (заказчик публикует проект, фрилансеры оставляют заявки). **Когда использовать: хорошее дополнение к Kwork** для более крупных и долгосрочных проектов — средний чек выше.
**Поиск проектов** — URL-паттерн `https://www.fl.ru/projects/?kind=5&pf={price_from}&pt={price_to}&page={page}` и фильтры по специализации (spec=4/8/19/38/30/39/7/36) — в `references/02-flru.md`.
**Примеры URL** — в `references/02-flru.md`.
**Навигация** — открой `https://www.fl.ru/projects/`, пауза 3 сек, `state`. FL.ru может требовать авторизацию для просмотра деталей: попроси пользователя войти в браузере и дождись подтверждения.
**Извлечение результатов** — поля карточки (заголовок, описание, бюджет, заявки, срок, дата, заказчик) — в `references/02-flru.md`.

## Workflow 3: Хабр Фриланс — IT-заказы

**Обзор** — фриланс-биржа от Хабра: качественные IT-заказы от технической аудитории, средний чек выше, заказчики адекватнее. **Когда использовать: только для IT-специалистов** — разработчики, QA, DevOps, дизайнеры интерфейсов, аналитики данных, ML-инженеры.
**Поиск задач** — URL-паттерн `https://freelance.habr.com/tasks?q={query}&page={page}`, фильтры (`categories[]`, `price_from`, `price_to`) и таблица категорий — в `references/03-habr.md`.
**Примеры URL** — в `references/03-habr.md`.
**Навигация** — открой `https://freelance.habr.com/tasks?q=python`, пауза 3 сек, `state`. Извлеки: название, описание, бюджет, количество откликов, требуемые навыки (теги), срок, рейтинг заказчика — в `references/03-habr.md`.

## Workflow 4: Telegram-каналы с заказами

**Поиск каналов через web_search** — готовые запросы («фриланс канал telegram [сфера] 2026» и др.) — в `references/04-telegram.md`.
**Популярные каналы (проверяй актуальность через web_search)** — таблица направлений и примеров запросов в `references/04-telegram.md`. Каналы динамичные — появляются и исчезают: не давай прямые ссылки, которые не проверил.
**Как использовать информацию из каналов** — извлеки суть заказа, оцени релевантность навыкам пользователя, добавь в общий список найденных заказов, предложи откликнуться.

## Workflow 5: Агрегация и скоринг

**Алгоритм подбора** — фильтрация по навыкам и бюджету, оценка конкуренции (меньше откликов = выше шанс), оценка заказчика (рейтинг + отзывы) и срочность (свежие заказы до 24 часов приоритетнее) — полный алгоритм в `references/05-scoring.md`.
**Формула скоринга** — `score = (budget_score × 0.3) + (skill_match × 0.3) + (competition_score × 0.2) + (reliability_score × 0.2)`; расшифровка слагаемых — в `references/05-scoring.md`.
**Формат выдачи результатов** — таблица топ-10 заказов с колонками (платформа, заказ, бюджет, откликов, срок, рейтинг, скор) и рекомендацией — шаблон в `references/05-scoring.md`.
**Детали по каждому заказу** — для топ-5 развёрнутая карточка (описание, требования, почему подходит, оценка времени, стоимость часа, ссылка) — шаблон в `references/05-scoring.md`.

## Workflow 6: Генерация отклика (cover letter)

**Принципы хорошего отклика** — конкретика (не «я умею всё», а «делал точно такой проект»), покажи понимание задачи, краткий план работы, реалистичные сроки с запасом 20%, 1-2 уточняющих вопроса — детали в `references/06-cover-letter.md`.
**Шаблон отклика** — персонализированный отклик под каждый заказ — в `references/06-cover-letter.md`.
**Адаптация под платформу** — Kwork: короткий отклик (до 1000 символов), упомяни рейтинг, предложи фиксированную цену; FL.ru: развёрнутый (до 3000 символов), портфолио, план работ с этапами; Хабр Фриланс: технически грамотный, конкретные технологии и подходы, кейсы из практики — в `references/06-cover-letter.md`.

## Workflow 7: Советы по ценообразованию

**Как рассчитать цену за заказ** — `Цена = (Желаемый_часовой_доход × Время_на_заказ) + Буфер_20%`; пример расчёта и округления — в `references/07-pricing.md`.
**Сравнение с рынком** — проверяй рыночные цены через web_search; готовые запросы в `references/07-pricing.md`.
**Вилка цен по специальностям (ориентир, проверяй актуальность)** — таблица по 11 специальностям (новичок / средний / опытный, ₽/час) — в `references/07-pricing.md`.

## Workflow 8: Отслеживание заявок

**Формат трекера** — веди таблицу откликов в контексте разговора: #, дата, платформа, заказ, бюджет, статус, примечание + итоги (всего откликов, потенциальный доход, конверсия) — шаблон в `references/08-tracking.md`.
**Статусы** — Черновик / Отправлен / Просмотр / Диалог / Принят / Отклонён / Отозван — полная таблица статусов в `references/08-tracking.md`.

## Workflow 9: Рекомендации по профилю

Советы по профилям на каждой площадке: **Kwork — профиль фрилансера** (заполнение на 100%, 3-5 кворков с портфолио, адекватные цены, быстрые ответы), **FL.ru — портфолио** (5-10 лучших работ, развёрнутое «О себе», тесты по специализации, статус «Проверенный»), **Хабр Фриланс** (заполненный профиль, карма 10+, публикация статей) — в `references/09-profile.md`.

## Антипаттерны

**Не делай так:**
- Откликайся на все подряд — выбирай релевантные
- Занижай цену «для первого заказа» — потом сложно поднять
- Копируй один отклик на все заказы — персонализируй
- Обещай нереалистичные сроки — лучше переоценить время
- Показывай технические детали browser-use
- Работай без предоплаты на крупных заказах (>10 000 ₽)
- Игнорируй красные флаги (новый аккаунт, нет отзывов, подозрительно дешёвый/дорогой)

**Делай так:**
- Начинай с Kwork (самый большой поток заказов)
- Проверяй 2-3 площадки для сравнения
- Генерируй уникальный отклик под каждый заказ
- Оценивай реальное время + буфер 20%
- Веди трекер откликов
- Спрашивай обратную связь после отклика
- Обновляй поиск каждые 1-2 дня (новые заказы)
