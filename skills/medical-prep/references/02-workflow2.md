# Workflow 2 — подготовка к приёму: полные детали

Читай перед выполнением Workflow 2 (шаги 1-5 из SKILL.md).

## Шаг 1: Определение цели визита

Спроси:
1. **К какому врачу идёшь?**
2. **Какая проблема / симптомы?** (кратко)
3. **Первичный приём или повторный?**
4. **Есть ли уже результаты анализов / обследований?**

## Шаг 2: Генерация списка вопросов врачу

**Формат:**
```
 Вопросы для {Специальность}:

 Обязательно спроси:
   1. Что может быть причиной моих симптомов?
   2. Какие обследования нужно пройти?
   3. Нужно ли сдать анализы перед следующим приёмом?
   4. Какие есть варианты лечения?
   5. Каких ограничений придерживаться до следующего визита?

 Дополнительно (для твоей ситуации):
   6. {вопрос конкретно по симптомам}
   7. {вопрос о влиянии на образ жизни}
   8. {вопрос о сроках / прогнозе}
```

**Поиск информации для подготовки:**
```
web_search(
  query="{симптом/диагноз} какие вопросы задать врачу {специальность}",
  count=5,
  freshness="noLimit"
)
```

## Шаг 3: Шаблон медицинской истории

**Предложи заполнить перед приёмом:**
```
 Шаблон для приёма (заполни / распечатай):

 1. ЖАЛОБЫ:
    - Что беспокоит: {опиши}
    - Когда началось: {дата/период}
    - Что провоцирует: {после еды / при нагрузке / ночью / стресс}
    - Что облегчает: {отдых / лекарство / поза}
    - Интенсивность (1-10): {оценка}

 2. ИСТОРИЯ:
    - Хронические заболевания: {перечисли}
    - Операции: {перечисли}
    - Травмы: {перечисли}
    - Аллергии: {на лекарства / продукты / другое}

 3. ЛЕКАРСТВА (сейчас принимаешь):
    - Название | Дозировка | Как давно

 4. ПРЕДЫДУЩИЕ ОБСЛЕДОВАНИЯ:
    - {анализ / УЗИ / МРТ} — {дата} — {результат}
```

## Шаг 4: Напоминание о документах

```
 Не забудь взять с собой:
   - Паспорт
   - Полис ОМС (если приём по ОМС)
   - СНИЛС
   - Результаты предыдущих анализов и обследований
   - Выписки из больницы (если были)
   - Список принимаемых лекарств
   - Направление (если есть)
   - Дневник симптомов (если вёл)
```

## Шаг 5: Советы для приёма

**До визита:**
- Запиши симптомы с хронологией
- Подготовь вопросы (выше)
- Не гугли диагноз — это усиливает тревогу

**На приёме:**
- Говори точно: где болит, как давно, что меняется
- Не преуменьшай и не преувеличивай
- Спрашивай, если не понял — врач обязан объяснить
- Записывай назначения или попроси расписать

**После визита:**
- Проверь, понятны ли назначения
- Запиши дату следующего приёма
- Проверь, все ли аналики/обследования назначены
