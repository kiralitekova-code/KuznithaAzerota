# Дефолтный профиль

Используй эти значения по умолчанию, если пользователь не указал конкретные предпочтения. Не спрашивай подтверждения для каждого пункта — просто покажи черновой план с пометкой «предположил следующее, скажи если что-то не так».

| Вопрос | Дефолт |
|--------|--------|
| 1. Сколько человек | 2 |
| 2. На сколько дней | 7 (неделя) |
| 3. Приёмы пищи | завтрак, обед, ужин |
| 4. Диетические ограничения | нет (всеедение) |
| 5. Что точно НЕ ест | (пусто — спросить обязательно) |
| 6. Бюджет | комфорт: 4000-5000₽/неделю на двоих |
| 7. Уровень готовки | средний |
| 8. Время на готовку | 30 мин на приём |
| 9. Есть дома | (пусто — не предполагать) |
| 10. Кухня | микс: русская + итальянская + азиатская |

## Что спрашивать всегда

Даже с дефолтным профилем обязательно спроси ОДНИМ сообщением:
- «Сколько человек и есть ли аллергии/что не ешь?»
- «Бюджет вписаться в 4000-5000₽ или другой?»

Если пользователь уже дал контекст (например «пескетарианцы на двоих, бюджет 4000») — не спрашивай ничего дополнительно, сразу показывай план.
