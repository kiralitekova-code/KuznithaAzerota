### Чек-лист осмотра

```
## Чек-лист для личного осмотра

### Документы
- [ ] Паспорт продавца (сверить с документами на авто)
- [ ] ПТС (оригинал! дубликат — вопрос, почему)
- [ ] СТС (свидетельство о регистрации)
- [ ] Диагностическая карта (если есть)
- [ ] Полис ОСАГО (переоформить)
- [ ] Договор купли-продажи (2 экземпляра)
- [ ] Акт приёма-передачи
- [ ] Сервисная книжка (если есть)

### Кузов — толщиномер ЛКП
- [ ] Капот (норма: 80-150 мкм)
- [ ] Крылья передние (норма: 80-150 мкм)
- [ ] Двери (норма: 80-150 мкм)
- [ ] Крылья задние (норма: 80-150 мкм)
- [ ] Крышка багажника (норма: 80-150 мкм)
- [ ] Крыша (норма: 80-150 мкм)
- [ ] >200 мкм = перекрашено, >500 мкм = шпатлёвка

### Кузов — визуально
- [ ] Зазоры между панелями (равномерность)
- [ ] Сколы и вмятины
- [ ] Ржавчина (пороги, арки, низ дверей)
- [ ] Стёкла (оригинальность — логотип производителя)
- [ ] Фары (мутность, сколы)
- [ ] ЛКП под уплотнителями (признаки перекраски)
- [ ] Бамперы (крепление, зазоры)

### Салон
- [ ] Износ руля (соответствует ли пробегу)
- [ ] Износ педалей
- [ ] Сиденья (провисание, потёртости)
- [ ] Потолок (провисание = вода)
- [ ] Запах (затхлость, бензин, сигареты)
- [ ] Приборная панель (ошибки, лампочки)
- [ ] Кондиционер / климат-контроль (работает)
- [ ] Магнитола / мультимедиа
- [ ] Стеклоподъёмники
- [ ] Обогрев сидений / руля

### Двигатель
- [ ] Работа на холодную (посторонние звуки)
- [ ] Работа на горячую (стук, троение)
- [ ] Подтёки масла
- [ ] Подтёки антифриза
- [ ] Уровень масла (по щупу)
- [ ] Уровень антифриза (в бачке)
- [ ] Цвет выхлопа (сизый = масло, чёрный = богатая смесь)
- [ ] Температура двигателя (не перегревается)

### Ходовая часть (тест-драйв)
- [ ] Руль (люфт, стук при повороте)
- [ ] Тормоза (увод в сторону, пульсация)
- [ ] Подвеска (стук на кочках)
- [ ] КПП (переключение плавное, без рывков)
- [ ] Сцепление (если МКПП — не буксирует)
- [ ] Шум в салоне (шумоизоляция)
- [ ] Круиз-контроль (если есть)

### Электроника
- [ ] ABS (лампочка гаснет после запуска)
- [ ] ESP (работает)
- [ ] Airbag (лампочка гаснет)
- [ ] Камера заднего вида
- [ ] Парктроники
- [ ] Навигация
- [ ] Bluetooth
```

### Чек-лист тест-драйва

```
## Тест-драйв

### Перед поездкой
- Двигатель холодный — попроси не прогревать до твоего приезда
- Проверь уровень всех жидкостей
- Осмотри место стоянки на предмет подтёков

### Во время поездки
- Прогрев: послушай двигатель, нет ли посторонних звуков
- Разгон: динамика, нет ли провалов, дым из выхлопной
- Торможение: машина не уводит, нет пульсации педали
- Повороты: руль возвращается, нет стука
- Неровности: подвеска не стучит, не пробивает
- Переключение передач: плавное, без рывков и хруста
- Разгон до 100-120 км/ч: нет вибрации, машина стабильна
- Торможение со скорости: эффективное, без увода

### После поездки
- Проверь температуру двигателя (не перегрелся)
- Осмотри под капотом — нет ли новых подтёков
- Включи кондиционер на максимум — работает ли
```

### Документы для сделки

```
## Документы для оформления покупки

1. **Договор купли-продажи** (3 экземпляра: продавец, покупатель, ГИБДД)
2. **Акт приёма-передачи** (с описанием состояния и комплектности)
3. **ПТС** — с внесёнными изменениями (новый собственник)
4. **СТС** — остаётся у продавца, покупатель получает новое
5. **Полис ОСАГО** — оформить на нового собственника до постановки на учёт

### Сроки
- Оформление договора: в день сделки
- Полис ОСАГО: в течение 10 дней
- Постановка на учёт в ГИБДД: в течение 10 дней
```

### Шаблон договора купли-продажи

```
## Договор купли-продажи транспортного средства

г. {Город}                                    «{число}» {месяц} 202{год} г.

{ФИО продавца}, паспорт серии {серия} №{номер}, выдан {кем, когда},
зарегистрированный по адресу: {адрес продавца},
именуемый в дальнейшем «Продавец», с одной стороны, и

{ФИО покупателя}, паспорт серии {серия} №{номер}, выдан {кем, когда},
зарегистрированный по адресу: {адрес покупателя},
именуемый в дальнейшем «Покупатель», с другой стороны,

заключили настоящий Договор о нижеследующем:

1. Продавец продаёт, а Покупатель покупает транспортное средство:
   Марка, модель: {марка} {модель}
   Год выпуска: {год}
   VIN: {VIN}
   Двигатель: №{номер}, {объём} л, {мощность} л.с.
   Кузов: №{номер}
   Цвет: {цвет}
   ПТС: {серия} №{номер}

2. Цена автомобиля: {сумма цифрами} ({сумма прописью}) рублей.

3. Автомобиль передаётся в исправном состоянии.
   Продавец гарантирует, что автомобиль не заложен, не состоит под арестом,
   не является предметом спора, не числится в розыске.

4. Расчёт производится {наличными / безналичным переводом} в полном объёме
   до подписания настоящего Договора.

5. Право собственности переходит к Покупателю с момента подписания
   настоящего Договора и Акта приёма-передачи.

Подписи:
Продавец: _______________ / {ФИО} /
Покупатель: _______________ / {ФИО} /
```
