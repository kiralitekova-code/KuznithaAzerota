### Поиск каналов через web_search

```
web_search: "фриланс канал telegram [сфера] 2026"
web_search: "telegram канал заказы [специальность]"
web_search: "фриланс вакансии telegram русские"
web_search: "удалённая работа telegram канал"
```

### Популярные каналы (проверяй актуальность через web_search)

| Направление | Примеры запросов для поиска |
|-------------|---------------------------|
| Все специальности | «фриланс канал telegram», «работа удалённо канал» |
| IT/Разработка | «telegram канал python заказы», «разработка фриланс telegram» |
| Дизайн | «дизайн фриланс telegram канал», «graphic design telegram вакансии» |
| Копирайтинг | «копирайтинг telegram заказы», «тексты фриланс канал» |
| Маркетинг | «маркетинг telegram вакансии», «SMM фриланс канал» |
| Видео | «видеомонтаж telegram заказы», «motion design канал» |

**Примечание**: Telegram-каналы динамичные — появляются и исчезают. Всегда проверяй актуальность через web_search. Не давай прямые ссылки на каналы, которые не проверил.

### Как использовать информацию из каналов

Найдя вакансии через web_search или web_reader (Telegram Web):
1. Извлеки суть заказа
2. Оцени релевантность навыкам пользователя
3. Добавь в общий список найденных заказов
4. Предложи откликнуться
