## Подсказки по парсингу выписок

У каждого банка свой формат. Общий подход через `code_execution` (Python, pandas):

```python
import pandas as pd
# определить кодировку и разделитель: utf-8-sig / cp1251, ; или ,
df = pd.read_csv('выписка.csv', sep=';', encoding='utf-8-sig', skiprows=...)
# нормализовать суммы: убрать \xa0, пробелы, заменить ',' на '.', распознать знак
```

### Сбербанк
- Формат: XLSX/CSV из веб-кабинета или PDF-выписка.
- Колонки: «Дата операции», «Сумма операции», «Описание», «Категория» (Сбер сам категоризует — можно использовать, но проверять).
- Сумма: отрицательная для расходов. Разделитель — запятая. Возможны неразрывные пробелы.
- В описании часто фигурирует `MCC`-код и название торговой точки — полезно для категоризации.

### Т-Банк (Тинькофф)
- Формат: CSV/PDF из приложения («Выписки» → «Скачать»).
- Колонки: «Дата операции», «Сумма платежа», «Категория», «MCC», «Описание», «Бонусы inkl. cashback».
- T-Банк даёт готовую «Категорию» и MCC — используйте как primary, при необходимости переклассифицируйте.
- Колонка «Бонусы» — размер начисленного кешбэка.

### ВТБ
- Формат: CSV/XLSX из ВТБ Онлайн.
- Колонки: «Дата», «Сумма», «Валюта», «Описание», «Категория».
- В описании — длинная строка с типом операции и контрагентом; MCC бывает не всегда.

### Альфа-Банк
- Формат: CSV/XLSX/PDF из Альфа-Мобайл / веб-кабинета.
- Колонки: «Дата», «Сумма», «Описание», «Категория».
- Категории Альфы достаточно точные, но иногда «прочее» — перепроверяйте по ключевым словам.

### Общие шаги парсинга
1. Прочитать файл, определить кодировку (`chardet` при необходимости) и разделитель.
2. Привести даты к единому формату (`%d.%m.%Y` → `datetime`).
3. Нормализовать суммы к float, сохранив знак (расход < 0, приход > 0).
4. Сопоставить «Описание» с ключевыми словами из таблицы выше; при наличии банковской «Категории» — использовать её как подсказку.
5. Агрегировать: сумма по категориям, по неделям/дням, выделить регулярные (повторяющиеся по сумме±5% и описанию) — это подписки и автоплатежи.
6. Сформировать сводку (доход/расход/баланс/топ трат/подписки).
