# Готовка и питание

Помогаем поесть вкусно, разнообразно и в бюджет: **меню → рецепты → список покупок**. Всё из продуктов ВкусВилла, Пятёрочки, Перекрёстка. Закрывает запросы «что приготовить», «меню на неделю», «рецепт», «составь список покупок» — пользователь получает готовый план и список, а не «погугли сам».

## Когда использовать

- «что приготовить на ужин/неделю», «составь меню», «план питания»
- конкретный рецепт (с граммовками, пошагово, под диету)
- «список покупок» из рецептов или меню
- адаптация под диету, бюджет, случай (праздник, поездка, дети)

## Когда НЕ использовать

- Автоматически добавить товары в корзину ВкусВилл — навык `vkusvill-cart` (этот навык готовит список, тот — выполняет заказ).
- Подобрать ресторан/доставку — не здесь.
- Специализированная медицинская диета (лечебный стол №5 и т.п.) — дайте общее направление, но подчеркните, что режим — по врачу.

## Что на выходе

1. **Меню/рецепты** — с граммовками, временем, КБЖУ, ценой за порцию.
2. **Список покупок** — агрегированный, по категориям, с маппингом на названия в магазинах + ориентировочной суммой.
3. (Опционально) формат для навыка `vkusvill-cart`, чтобы сразу заказать.

## Инструменты

| Задача | Инструмент |
|---|---|
| Вдохновение/проверка рецептов, КБЖУ, цены | MCP `web_search`, `web_reader` |
| Актуальные цены в магазине | `browser-use` (или навык `vkusvill-cart`) |
| Справочник КБЖУ | файл ресурсов `products.md` |
| Профиль по умолчанию | `profiles/default.md` |

Цены меняются — не зашивайте значения, проверяйте через web search/browser-use. КБЖУ стабильно — берите из `products.md`, при отсутствии продукта ищите через web search.

## Шаг 1. Опрос (или профиль по умолчанию)

Перед меню спроси (можно одним сообщением):

1. Сколько человек (порции)
2. На сколько дней (1 / 3 / неделя)
3. Приёмы пищи (завтрак / обед / ужин / перекусы)
4. Диетические ограничения (веган, безлактозное, безглютеновое, пост, аллергии)
5. Что точно НЕ ест
6. Бюджет на период (₽)
7. Уровень готовки (новичок / средний / уверенный)
8. Время на приём (мин)
9. Что уже есть дома
10. Предпочтения по кухне (русская, итальянская, азиатская, смешанная)

Если пользователь дал контекст («веганы на двоих, 4000₽») — не переспрашивай, сразу показывай план с пометкой «предположил следующее, скажи, если что не так». Дефолты — в `profiles/default.md` (2 человека, неделя, комфорт 4000–5000₽, микс кухонь).

## Шаг 2. Формат рецепта

```
### [Название]
**Порций:** N  **Время:** X мин
**КБЖУ на порцию:** Ккал / Б / Ж / У  **Цена за порцию:** ~XXX ₽

**Ингредиенты:**
- Продукт — N г / шт
- ...

**Приготовление:**
1. Шаг (одно действие)
2. ...
```

Правила: точные граммовки (не «по вкусу» — только соль/перец); реальное время под уровень готовки; продукты из российских магазинов; минимум отходов (открытую пачку/банку используем в другом рецепте); пошагово.

Поиск рецептов через `web_search`: `[блюдо] рецепт пошагово`, адаптация под диету `[блюдо] вегетарианский/без глютена/постный`, замены `[продукт] чем заменить`. Берём технику и пропорции, перерабатываем под формат навыка.

## Шаг 3. Типы планов

- **Быстрый (1 день)**: рецепты на запрошенные приёмы + объединённый список покупок.
- **Недельный (5–7 дней)**: таблица день × приём → рецепт; batch cooking (2–3 блюда на 2–3 дня, контейнерная система); список на неделю по категориям; один приём в выходные свободный.
- **Тематический**: вечеринка, детский праздник, романтический ужин, дача/пикник, праздничный стол.

## Шаг 4. КБЖУ и цена

- **КБЖУ** — из `products.md` (на 100 г). Нет продукта — `web_search`: `[продукт] калорийность белки жиры углеводы на 100г`. Не выдумывайте.
- **Цены** — приблизительные из `products.md` как ориентир; для точности `web_search` `[продукт] цена ВкусВилл 2026` или browser-use.

## Шаг 5. Диеты — замены

- **Вегетарианство**: тофу, яйца, творог, бобовые+крупы (полный аминопрофиль), сыр.
- **Веганство**: тофу/темпе/сейтан, бобовые+крупы, лён (Омега-3), B12-добавка, растительное молоко, кокосовые сливки.
- **Безлактозное**: растительное молоко, безлактозный творог/сыр (ВкусВилл), тофу, кокосовый йогурт.
- **Безглютеновое**: рис, гречка, киноа, кукуруза; макароны из риса/кукурузы/гречки; хлеб без глютена; овсянка только с маркировкой GF.
- **Православный пост**: исключить мясо/рыбу/молочку/яйца; белок из чечевицы (24г), нута (20г), фасоли (21г), тофу, орехов; по выходным — вино и елей.

## Шаг 6. Кухни мира (базовые ориентиры)

- **Русская**: борщ, щи, котлеты, голубцы, каши, оливье, запеканки.
- **Итальянская**: паста (карбонара, болоньезе, песто), ризотто, пицца, лазанья.
- **Азиатская**: удон/рамен, жареный рис, вок (курица/тофу + овощи), том-ям, гёдза.
- **Кавказская**: хачапури, хинкали, шашлык, лобио, сациви, хычины.

## Шаг 7. Бюджетные уровни (на человека в день)

- **Эконом (до 400₽)**: крупы, курица, яйца, творог, сезонные овощи; простые рецепты 15–20 мин.
- **Комфорт (400–700₽)**: + индейка, рыба, авокадо, сыр, орехи.
- **Премиум (700+₽)**: + говядина, сёмга, импортный сыр.

## Список покупок

### Агрегация ингредиентов

1. Одинаковые продукты суммируются (куриная грудка 150г + 200г = 350г).
2. Разные формы — отдельно (филе ≠ фарш ≠ бёдра; свежее ≠ замороженное; сырые ≠ консервы).
3. Конвертация единиц: г→кг (÷1000, если >500г), мл→л (÷1000, если >500мл), зубчик≈5–7г, ст.л. масла=15мл, ч.л. специй≈5г, пучок зелени≈30–50г, щепотка — игнорировать.
4. Округление: мясо/рыба/овощи — до 100г или поштучно; крупы — до 100г; молочка — до упаковки; масло — 1 бутылка (если <200мл, считаем что есть); специи — если <1 ч.л., не включаем; яйца — до десятка.

### Категории для группировки

🥩 Мясо и птица · 🐟 Рыба и морепродукты · 🥛 Молочные · 🥚 Яйца · 🥬 Овощи и зелень · 🍎 Фрукты и ягоды · 🌾 Крупы и макароны · 🫘 Бобовые и консервы · Масло и соусы · 🧈 Орехи и семена · 🍞 Хлеб и выпечка · 🧊 Замороженные · 🫙 Тофу и растительное · Специи.

### Маппинг на ВкусВилл (примеры)

| Рецептное | Поиск на ВкусВилл |
|---|---|
| Куриная грудка | «Филе куриной грудки» |
| Индейка филе | «Филе индейки» |
| Творог 5% | «Творог 5%» |
| Гречка | «Крупа гречневая» |
| Брокколи (заморозка) | «Брокколи замороженная» |
| Тофу | «Тофу» |
| Растительное молоко | «Молоко овсяное» / «Молоко миндальное» |
| Безглютеновые макароны | «Макароны без глютена» / «Макароны из риса» |

### Замены (до 2 попыток автоматически)

Если товара нет: бедро куриное ↔ филе грудки ↔ филе индейки; горбуша ↔ минтай ↔ треска; сёмга ↔ лосось ↔ кета; творог 5% ↔ 9% ↔ обезжиренный; тофу ↔ адыгейский ↔ брынза; греческий йогурт ↔ сметана 10–15% ↔ натуральный йогурт; нут ↔ фасоль красная ↔ чечевица; киноа ↔ булгур ↔ кускус. Полная таблица замен — в `products.md`.

```

🥛 Молочные

```

Для навыка `vkusvill-cart` — формат с типом единицы (`kg`/`pcs`/`pack`):
```

2. "Творог 5%" — 2 шт (pcs)
```

## Пресеты меню

При «собери корзину/меню на неделю» — подбери пресет по ограничениям (бюджет, белок, кухни) и **генерируй уникальные рецепты**, не повторяй одни и те же блюда. Пресеты задают ограничения, а не конкретные рецепты; для цен — проверяй через web search/browser-use. Примеры: «Комфорт» (2 чел, ~3500–5000₽/нед, микс кухонь, batch cooking), «Пескетарианский» (рыба/морепродукты/тофу/бобовые), «Безглютеновый» (рис/гречка/киноа, проверка каждого ингредиента).

## Антипаттерны

- Рецепт без точных граммовок («щепотка», «по вкусу» — только для соли/перца).
- «Четвертинка лимона» — продают целыми, пересчитайте.
- 5 разных блюд на 5 дней — нереально; batch cooking: 2–3 блюда на 2–3 дня.
- Список на 1 ч.л. продукта — не покупают пачку ради ложки; считайте, что базовое есть дома.
- Не учли открытые упаковки — используйте в других рецептах.
- Зашитые цены — проверяйте актуальные через web search/browser-use.
