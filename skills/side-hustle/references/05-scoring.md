### Алгоритм подбора

После сбора заказов со всех платформ:

1. **Фильтрация по навыкам** — оставь только релевантные заказы
2. **Фильтрация по бюджету** — отсеки слишком дешёвые и подозрительно дорогие
3. **Оценка конкуренции** — чем меньше откликов, тем выше шанс
4. **Оценка заказчика** — высокий рейтинг + отзывы = надёжный
5. **Срочность** — свежие заказы (до 24 часов) приоритетнее

### Формула скоринга

Для каждого заказа рассчитай скор:

```
score = (budget_score × 0.3) + (skill_match × 0.3) + (competition_score × 0.2) + (reliability_score × 0.2)
```

Где:
- `budget_score` (0-1): насколько бюджет соответствует ожиданиям пользователя
- `skill_match` (0-1): насколько навыки соответствуют требованиям
- `competition_score` (0-1): 1 / (1 + количество_откликов) — меньше конкурентов = лучше
- `reliability_score` (0-1): рейтинг заказчика / 5
