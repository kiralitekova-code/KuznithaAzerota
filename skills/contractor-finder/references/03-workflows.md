## Workflow 2: Анализ портфолио

### Шаг 1: Открыть профиль

```bash
# По ссылке от пользователя
browser-use --headed open "URL_ПРОФИЛЯ"
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"

# Или по имени — сначала найти через поиск
browser-use --headed open "https://profi.ru/search/?q=ИМЯ+ФАМИЛИЯ"
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"
```

### Шаг 2: Извлечь фото портфолио

```bash
# Получить URL всех фото в портфолио
browser-use eval "JSON.stringify(Array.from(document.querySelectorAll('[class*=\"portfolio\"] img, [class*=\"gallery\"] img, [class*=\"work-sample\"] img, [class*=\"photo\"] img')).slice(0,20).map(img => ({src: img.src, alt: img.alt || ''})))"
```

### Шаг 3: Анализ каждого фото

Для каждого фото используй `image_analysis`:

```
image_analysis:
  imageSource: [URL фото]
  prompt: "Оцени качество выполненной работы на этом фото. Определи: качество материалов, аккуратность исполнения, соответствует ли заявленной категории услуг. Оцени от 1 до 10. Укажи: что сделано хорошо, что можно улучшить."
```

### Шаг 4: Сводная оценка портфолио

```
АНАЛИЗ ПОРТФОЛИО: [Имя исполнителя]
Площадка: [Profi.ru / Avito / Яндекс.Услуги / YouDo]
Фото проанализировано: [N] из [M]

Средняя оценка качества: X.X / 10

Распределение:
- Отлично (8-10): N фото (XX%)
- Хорошо (6-7): N фото (XX%)
- Средне (4-5): N фото (XX%)
- Плохо (1-3): N фото (XX%)

Сильные стороны:
- [конкретные наблюдения]

Слабые стороны:
- [конкретные наблюдения]

Вердикт: [Высокое / Среднее / Низкое] качество работ.
Рекомендация: [стоит нанимать / с осторожностью / не рекомендуется]
```

## Workflow 3: Проверка репутации

### Шаг 1: Поиск отзывов

```bash
# Поиск отзывов через web_search
web_search "ИМЯ_ИСПОЛНИТЕЛЯ отзывы ГОРОД"
web_search "ИМЯ_ИСПОЛНИТЕЛЯ мошенчик обман ГОРОД"
web_search "ИМЯ_ИСПОЛНИТЕЛЯ Profi.ru Avito отзывы"
```

### Шаг 2: Проверка на сайтах отзывов

```bash
# Прочитать страницу отзывов
web_reader "https://otzovik.com/search/?q=ИМЯ_ИСПОЛНИТЕЛЯ"
web_reader "https://irecommend.ru/search?query=ИМЯ_ИСПОЛНИТЕЛЯ"
```

### Шаг 3: Проверка через web_search

```bash
# Поиск жалоб
web_search "ИМЯ_ИСПОЛНИТЕЛЯ жалоба Роспотребнадзор"
web_search "ИМЯ_ИСПОЛНИТЕЛЯ суд иск некачественные услуги"

# Поиск на форумах
web_search "ИМЯ_ИСПОЛНИТЕЛЯ forum отзыв опыт"
```

### Шаг 4: Сводка репутации

```
ПРОВЕРКА РЕПУТАЦИИ: [Имя исполнителя]

Отзывы на площадках:
- Profi.ru: X.X (N отзывов)
- Avito: X.X (N отзывов)
- Яндекс.Услуги: X.X (N отзывов)
- YouDo: X.X (N отзывов)

Внешние источники:
- otzovik.com: [найдено / не найдено]
- irecommend.ru: [найдено / не найдено]
- Форумы: [найдено / не найдено]

Красные флаги:
- [список или «Не обнаружено»]

Частая похвала:
- [топ-3 позитивных темы в отзывах]

Общий настрой отзывов: [Положительный / Смешанный / Отрицательный]

Рекомендация: [Высокая надёжность / Средняя / Есть риски / Не рекомендуется]
```

## Workflow 4: Связь и бронирование

### Шаг 1: Генерация сообщения

Составь персонализированное сообщение на основе требований пользователя:

```
Здравствуйте, [Имя мастера]!

Меня интересует [тип услуги]. Детали:
- Адрес: [район/адрес]
- Объём работ: [описание]
- Желаемые сроки: [когда]
- Бюджет: [диапазон]

Подскажите, когда сможете посмотреть объект и оценить стоимость?
```

### Шаг 2: Навигация к форме связи

```bash
# Открыть профиль исполнителя
browser-use --headed open "URL_ПРОФИЛЯ"
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"

# Найти кнопку связи
browser-use state
# Или через eval:
browser-use eval "JSON.stringify(Array.from(document.querySelectorAll('button, a')).filter(el => /написать|связаться|заказать|сообщение|заказать/i.test(el.textContent)).map(el => ({text: el.textContent.trim(), tag: el.tagName})))"
```

### Шаг 3: Заполнение формы

```bash
# Кликнуть кнопку связи
browser-use click "text=Написать"

# Заполнить сообщение
browser-use type "Здравствуйте, ..."

# Заполнить телефон (ТОЛЬКО если пользователь разрешил!)
# НИКОГДА не вводи телефон/email без явного подтверждения пользователя
```

### Шаг 4: Подтверждение перед отправкой

**КРИТИЧЕСКОЕ ПРАВИЛО**: Никогда не отправляй сообщение без подтверждения пользователя!

```
ГОТОВО К ОТПРАВКЕ:

Кому: [Имя мастера] на [Платформа]
Сообщение:
[текст сообщения]

Отправить? (Да / Нет / Изменить)
```

Только после ответа «Да» — нажимай кнопку отправки.

### Шаг 5: Отправка

```bash
browser-use click "text=Отправить"
node -e "new Promise(r=>setTimeout(r,2*1000)).then(process.exit)"
browser-use state
```

### Шаг 6: Отслеживание отправленных запросов

Храни список отправленных запросов в контексте:

```
SENT_INQUIRIES:
1. [Имя мастера] | [Платформа] | [Дата] | [Статус: отправлено/ответ получен]
2. [Имя мастера] | [Платформа] | [Дата] | [Статус: отправлено/ожидает]
```

## Workflow 5: Оценка стоимости услуг

### Шаг 1: Сбор рыночных цен

```bash
# Поиск текущих цен
web_search "ремонт квартир цена ГОРОД 2026 за м²"
web_search "стоимость услуг электрика ГОРОД 2026"
web_search "[тип услуги] расценки прайс ГОРОД"
```

### Шаг 2: Чтение прайс-листов

```bash
# Прочитать страницу с ценами
web_reader "https://profi.ru/ГОРОД/remont/kalkulyator/"
web_reader "https://uslugi.yandex.ru/calc/[категория]"
```

### Шаг 3: Сравнение с предложением подрядчика

```
ОЦЕНКА СТОИМОСТИ: [тип услуги] в [город]

Рыночный диапазон:
- Минимум: X XXX ₽
- Среднее: X XXX ₽
- Максимум: X XXX ₽

Предложение подрядчика: X XXX ₽

Позиция на рынке: [Ниже рынка / В пределах нормы / Выше рынка]

Если значительно ниже рынка:
ВНИМАНИЕ: Цена значительно ниже рыночной. Возможные причины:
- Недостаточный опыт
- Скрытые доплаты
- Некачественные материалы
Рекомендация: уточните, что включено в стоимость

Если значительно выше рынка:
Проверьте, что входит в стоимость:
- Материалы
- Гарантия
- Уборка после работ
- Срочность
```

### Шаг 4: Факторы, влияющие на цену

| Фактор | Влияние на цену |
|--------|----------------|
| Срочность (сегодня/завтра) | +20-50% |
| Выходные / праздники | +20-30% |
| Центр города | +10-20% |
| Высотные работы | +30-100% |
| Демонтаж старого | +15-30% |
| Вывоз мусора | +5-15% |
| Гарантия на работы | +10-20% |
| Закупка материалов подрядчиком | +10-25% (наценка) |
