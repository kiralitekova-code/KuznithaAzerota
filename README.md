# ⚒️ Кузница Азерота (Forge of Azeroth)

Браузерная 2D-игра про автоматизацию кузнечного производства в фэнтези-сеттинге:
стройте рудники, плавильни и верстаки, связывайте их конвейерами, выполняйте
задания и производите Древнее оружие. 100 уровней, 15 зданий, апгрейды после
каждого уровня, rewarded-реклама, автосохранение в IndexedDB.

**Играть:** опубликована на хостинге статикой — см. раздел «Деплой» ниже.

## Стек

| Слой | Технология |
|---|---|
| Язык | TypeScript (strict) |
| Сборка | Vite 6 |
| Рендер карты | PixiJS 8 (WebGL) |
| UI | React 18 + Zustand |
| Стили | TailwindCSS + CSS-анимации + Lottie |
| Сохранения | IndexedDB (`idb-keyval`), автосейв каждые 10 с |
| Звук | Howler.js |
| Тесты | Vitest (23 юнит-теста core-логики) |

## Быстрый старт

```bash
npm install        # зависимости (локально, в git не коммитятся)
npm run dev        # http://localhost:5173
```

Прод-сборка и проверка:

```bash
npm run build      # typecheck (tsc --noEmit) + vite build → dist/
npm test           # vitest run
npm run preview    # локальный просмотр dist/ на :4173
```

Полезные скрипты:

- `npm run assets` — процедурная генерация всех спрайтов/звуков/Lottie в `public/assets` (CC0, заглушки не нужны — ассеты генерятся кодом);
- `npm run levels` — перегенерация 100 уровней из `tools/gen-levels.mjs`.

## Как играть

1. **Рудник / Лесопилка** добывают сырьё; **Угольная шахта** — топливо.
2. **Печи** плавят руду в слитки (нужен уголь), **верстаки** делают компоненты.
3. **Конвейеры** (строются перетаскиванием направления) автоматически переносят
   предметы между зданиями.
4. **Сборочный стол** производит Древнее оружие — сдавайте по заданиям справа или продавайте за золото.
5. Выполните все задания уровня → выберите 1 улучшение из 3 (пул 5 типов) → следующий уровень.

Управление: колесо мыши — зум, ЛКМ-drag по земле — панорама, клик по зданию в тулбаре — режим постройки, ПКМ — снос. Кнопки ×1/×2/×4 — скорость симуляции.

## Структура проекта

```
src/
├─ core/        engine.ts (симуляция 20 Гц), EventBus, SaveManager (IndexedDB + миграции)
├─ data/        buildings.ts (15 зданий), items.ts, recipes, levels.ts (100 ур.), upgrades.ts
├─ render/      GameRenderer.ts (Pixi: грид, здания, конвейеры, партиклы), камера
├─ systems      внутри engine.ts: mining / smelting / crafting / power / conveyor / quests / economy
├─ ui/          screens (Loading, MainMenu, Level, Upgrade, Credits) + компоненты
├─ ads/         IAdProvider + MockAdProvider (dev) + YandexAdProvider (прод)
├─ audio/       AudioManager (Howler)
└─ store/       gameStore (Zustand)
tests/          engine.test.ts — логика симуляции
tools/          генераторы ассетов и уровней
```

## Реклама

Интерфейс `IAdProvider`: rewarded-награды («×2 золото за задание», «×2 скорость на 5 мин»,
«мгновенная достройка»). В dev работает `MockAdProvider` (эмуляция 3 с). Для прода при
публикации на Yandex.Games SDK подхватывается автоматически (`YandexAdProvider`).

## Деплой

Статическая сборка из `dist/` — любой статик-хостинг:

- **GitHub Pages**: workflow `.github/workflows/deploy.yml` собирает и публикует на push в `main`;
- **Vercel / Netlify**: build command `npm run build`, output `dist`;
- Важно: репозиторий **не содержит** `node_modules/` и `dist/` — CI устанавливает зависимости сам (`npm ci`), иначе сборочные машины получают битые права на бинарники (`sh: tsc: Permission denied`).

## Лицензионная чистота

Все спрайты, тайлы, иконки, звуки и Lottie-анимация генерируются процедурно
(`tools/gen-assets.mjs`) и распространяются как CC0. Имена и визуал — оригинальные,
похожие на Warcraft, но без защищённых материалов Blizzard.

## Качество

- `tsc --noEmit` строгий — 0 ошибок;
- 23/23 юнит-тестов зелёные;
- FPS 60 на среднем ноутбуке, адаптив под планшет.
