# Карьера

Один навык на весь путь поиска работы и роста: **резюме → отклики → собеседование → офер → переговоры**. Закрывает запросы «помоги с резюме», «найти работу», «подготовиться к собеседованию», «как просить прибавку». Пользователь получает готовые артефакты (резюме, сопроводительное, план подготовки, скрипт переговоров), а не общие советы.

## Когда использовать

- резюме (hh.ru), сопроводительное письмо, профиль, позиционирование
- поиск вакансий (hh.ru / SuperJob / Хабр Карьера), стратегия откликов
- подготовка к собеседованию, тренировка (mock), кейсы, тестовые
- зарплатные переговоры, оценка оффера, карьерная траектория

## Когда НЕ использовать

- Executive search / C-level, глубокий карьерный кризис, смена профессии с травмой — порекомендуйте человеческого ментора (mentors.hh.ru, карьерные консультанты).
- Релокация за рубеж со сложной визой — дайте ориентир, но нюансы у специалиста.

## Рынок РФ, 2026 (контекст)

Рынок работодателя: индекс конкуренции на hh.ru ~22,9 (год назад 11,6 — в 2× сложнее); IT-медиана 180–220 тыс ₽/мес, −20% от пика 2024, прогноз +8–13% (опытные до +30%); Junior/Middle сжаты — для Junior критично портфолио; удалёнка сокращается (возврат к гибриду 2–3 дня); владение LLM-инструментами теперь ожидание, а не бонус; прозрачность зарплат растёт.

## Резюме (hh.ru)

**Порядок блоков:** фото/контакты → должность+зарплата → «О себе» → опыт (обратная хронология) → образование → ключевые навыки → курсы → языки.

**Обязанности → достижения по XYZ:** «Достиг [X = измеримое], сделав [Y = действие], что привело к [Z = польза бизнесу]». Глаголы силы: руководил / внедрил / увеличил / сократил / разработал — никогда «участвовал / помогал / работал».

**«О себе» (3–4 строки):** «[N] лет опыта в [сфера/роль], специализация на [экспертиза]. Главные достижения: [достижение 1 + цифра], [достижение 2 + цифра]. Ищу [тип роли] в [тип компании].»

**Адаптация под вакансию (4 шага):** вытащить hard-skills → soft-skills → выровнять формулировку должности → подогнать частоту ключевых слов до 2–3× (не спам-фильтр, не пропуск).

**ATS-формат:** 1–2 страницы A4 (3 при 10+ годах); sans-serif 11–12 pt, имя 14 pt; без таблиц/сайдбаров; PDF для прямой отправки; шрифты стандартные. Рекрутер сканирует 6–10 секунд.

**Не использовать в РФ:** «References available upon request», «Dear Hiring Manager», «Objective» — это US-шаблоны. Уберите школу/хобби/семейное.

## Сопроводительное письмо

**3 абзаца, 150–200 слов:**
1. **Почему эта компания** (40–60 слов) — конкретный факт, не «нравится ваша компания».
2. **Почему подходите** (60–80 слов) — 1–2 достижения XYZ, привязанных к требованиям вакансии.
3. **Призыв** (20–30 слов) — предложить интервью, упомянуть гибкость, спасибо.

**Лимиты по платформам:** hh.ru ~5000 знаков (держите 1500–3000), SuperJob ~3000, Хабр Карьера ~2000.

Обращение: «Здравствуйте, команда [компания]» или имя рекрутера. Заключение: «Готов предоставить рекомендации по запросу».

## Поиск вакансий (hh.ru / SuperJob / Хабр Карьера)

### Общая процедура (browser-use)

1. Если `browser-use` не установлен — активируйте навык `browser-use` (автоустановка; скажите «настраиваю поиск…», не показывайте техдетали).
2. **Соберите URL с параметрами** (надёжнее заполнения формы) → `browser-use --headed open <url>` → `browser-use state`.
3. Извлеките карточки вакансий, откройте детали.
4. Отклик: проверить, что пользователь залогинен (**никогда не вводите логин/пароль за него** — попросите залогиниться в открытом браузере и подтвердить) → «Отклинуться» → приложить сопроводительное → отправить → подтвердить.

**Надёжность селекторов:** у hh.ru хэши CSS-классов меняются при каждом деплое — опирайтесь на текст и структуру, а не на селекторы. CAPTCHA — ждите 30–60 с, в `--headed` пользователь решит сам. Cookie-баннер — «Принять»/Escape; модалки — Escape. Кириллицу в URL кодируйте.

### Дифференциалы платформ

| | hh.ru | SuperJob | Хабр Карьера |
|---|---|---|---|
| **Для чего** | Всё (~70% рынка) — **начинать всегда здесь** | Не-IT: офис, производство, медицина, стройка, торговля, бухгалтерия | **Только IT**; открытые зарплаты, матчинг по навыкам |
| Base URL | `hh.ru/search/vacancy?` | `superjob.ru/vacancy/search/?` | `career.habr.com/vacancies?` |
| Запрос | `text` | `keywords` | `q` |
| Город | `area` (МСК=1, СПб=2, **Удалёнка=115**, РФ=113) | `geo[c][0]` (МСК=4, СПб=14) | `city_id` (МСК=680, СПб=679, **Удалёнка=778**) |
| Опыт | `between1And3` / `between3And6` / `moreThan6` | `1-3` / `3-6` / `moreThan6` | `junior` / `middle` / `senior` / `lead` |
| Удалёнка | `schedule=remote` | `place_of_work[0]=2` (1 офис / 3 гибрид) | `remote=true` + `city_id=778` |
| Навыки | ключевые слова | catalogues/profession | **`skills[]` стандартизированные слаги** (python, react, kubernetes…) |
| Сопроводительное | ~5000 | ~3000 | ~2000 |
| Зарплата | часто скрыта | часто скрыта | **~100% — лучший источник IT-зарплат** |

Источники зарплат: stats.hh.ru (бесплатно), Хабр Карьера `/salaries`, finder.vc (верифицированные), SuperJob `/research/`. Всегда указывайте источник и период.

## Стратегия откликов

- **Трекинг:** Company / Role / Platform / Date / Status / Salary / Contact / Follow-up / Notes. Воронка: Отклик → Просмотр → Приглашение → Интервью1/2 → Оффер → Принято/Отклонено.
- **Тайминг:** лучшее время — вт–чт 9–11 утра; золотое окно — первые 24–48 ч после публикации; >30 дней — вероятно закрыто.
- **Объём в неделю:** Junior 25–40, Middle 15–25, Senior 8–15, Lead+ 5–10 (Senior+ — качество важнее количества).
- **Follow-up:** день 3–5 (первый), 7–10 (второй), 14+ — закрывать. После 2 безответных — стоп.
- **Бенчмарки конверсии:** Отклики→Просмотры >40% хорошо / <15% плохо; Просмотры→Приглашение >15% / <5%; Приглашение→Оффер >20% / <8%. Сопроводительное поднимает Просмотры→Приглашение на **30–50%**.
- **Никогда не откликайтесь дважды** на одну вакансию с разных платформ.

## Подготовка к собеседованию

**STAR:** Ситуация (20%) → Задача → Действие (**60%**, 2–3 шага, говорите «я», а не «мы») → Результат (20%, измеримый + урок).

**5 историй** (каждая закрывает 3–5 вопросов, ~300–400 слов, 2–3 мин устно): (1) лидерство в кризисе, (2) провал и восстановление, (3) успех под давлением, (4) кросс-функциональное взаимодействие/убеждение, (5) инициатива/улучшение.

**Топ-10 вопросов РФ** — структура ответов. «Расскажите о себе» = Настоящее–Прошлое–Будущее. «Почему уходите?» = не ругайте прошлого работодателя. «Слабые стороны?» = реальная слабость + митигация, не «перфекционист».

**Встречные вопросы** (3–5): роль/команда/компания/процессы. Никогда не «у меня нет вопросов».

**Кейсы:** прибыль (Profit=Выручка−Издержки), выход на рынок, ценообразование, M&A. Уточнить → Структура → Анализ → Рекомендация.

**Тестовые (IT/дизайн/маркетинг):** договоритесь о дедлайне, лимит 4–8 ч; откажитесь от 20+ ч (бесплатный труд); крупные — выкладывайте в свой GitHub под MIT после сдачи, чтобы защитить авторство.

**Тренировка (mock):** по одному вопросу за раз → оценка по 4 осям (структура, конкретика, «я» vs «мы», рефлексия) → коучинг → следующий.

## Переговоры о зарплате

**5 вопросов подготовки:** минимум (walk-away), цель, рыночный диапазон, ваш рычаг (ценность за первые 6 мес), альтернативы (другой оффер?).

**4 техники:**
1. Диапазон с верхней границей на цели («280–320, цель 300–330», а не «250–350»).
2. Якорь: встречный вопрос о бюджете; если заставляют — цель +15–20%.
3. **Совокупная компенсация:** оклад (12 vs 13 мес), KPI-бонус (%/период/история), LTI/опционы (вестинг+клифф), ДМС (вкл. стоматология/психология/семья), бюджет обучения, техника, релокация, гибкость.
4. Никогда не решайте на месте — просите 2–3 дня.

**Скрипты:** оффер ниже ожиданий; спрашивают текущую зарплату (не раскрывайте — переведите на рыночный диапазон); **ловушка контроффера** (85% — работодатель тянет время на замену; большинство всё равно уходят за 6–12 мес — вежливо отказывайте).

**Уровни (Москва 2026, тыс ₽/мес):** Junior 80–120 / Middle 140–200 / Senior 220–300 / Lead-Staff 300–450 / Principal-Head 400–700. Развилка специалист vs менеджер: «хороший Senior на 30% ценнее плохого Team Lead».

## Позиционирование

Telegram — основной деловой мессенджер РФ (реальный @username, имя+специализация, bio 70 знаков, открытое «был(а)»; канал = сигнал-портфолио). hh.ru: точная желаемая должность, 7–12 тегов навыков, обновление каждые 2 недели (алгоритм бустит активные), указывайте зарплату (без цифр резюме тонет), готовность к релокации. LinkedIn — для международного/мультинационального. GitHub — портфолио для технических ролей.

## Границы и безопасность

- **Никогда не авто-откликайтесь и не вводите учетные данные** — пользователь сам логинится в открытом браузере и подтверждает; навык только жмёт «Отклинуться» и чертит сопроводительное.
- **Не откликайтесь дважды** на одну вакансию с разных платформ.
- **Указывайте источник и период**, цитируя зарплаты.
- **Красные флаги работодателя** (не откликаться / предупредить): зарплата сильно ниже рынка, размытые обязанности, «на Junior нужно 5 лет опыта», эвфемизмы «динамичная команда»/«семейная» (=выгорание/нарушение границ), безымянная компания, 10+ одинаковых вакансий (=текучка), неоплачиваемое тестовое >4 ч, зарплата «в конверте/обсудим позже», нет онбординга, руководитель поливает бывших сотрудников.

## Антипаттерны

- Резюме-обязанности вместо достижений; общие метрики; английские клише в переводе; «О себе» водой; >3 страниц; несогласованные даты.
- Сопроводительное «вода» и «нравится ваша компания»; один шаблон на все платформы без учёта лимитов знаков.
- Спам-отклики без трекинга; игнорирование follow-up; двойные отклики.
- На собеседовании — «мы» вместо «я», отсутствие измеримого результата, ругань прошлого работодателя.
- На переговорах — решение на месте, раскрытие текущей зарплаты, слепое принятие контроффера.
