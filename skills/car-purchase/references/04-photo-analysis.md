### Извлечение URL фотографий

Открой страницу объявления через browser-use:

```bash
browser-use --headed open "URL_ОБЪЯВЛЕНИЯ"
node -e "new Promise(r=>setTimeout(r,4*1000)).then(process.exit)"
```

```javascript
browser-use eval "
  const images = document.querySelectorAll('[class*=\"gallery\"] img, [class*=\"photo\"] img, [class*=\"image\"] img, [class*=\"slide\"] img');
  const urls = [];
  images.forEach(img => {
    const src = img.src || img.dataset.src || img.dataset.full || '';
    if (src && !src.includes('avatar') && !src.includes('logo') && !src.includes('icon')) {
      urls.push(src);
    }
  });
  JSON.stringify(urls.slice(0, 20));
"
```

### Промпты для image_analysis

#### Кузов (экстерьер)

Для каждого фото экстерьера отправляй:

> «Проанализируй фото этого автомобиля. Ищи признаки: перекраска (разный оттенок на панелях, разная шагрень), зазоры между деталями кузова (неравномерные = ремонт после ДТП), сколы, вмятины, ржавчина, состояние шин и дисков, трещины на стёклах, состояние оптики (мутные фары = возраст/пробег). Оцени общее состояние кузова от 1 до 10.»

#### Салон (интерьер)

> «Оцени салон этого автомобиля. Проверь: износ руля (блестящий = большой пробег), износ сидений (провисание, потёртости — соответствует ли заявленному пробегу), состояние панели приборов (царапины, трещины), потолок (провисание = затопление или курение), запахи (затхлость = проблемы с водой, сигаретный запах), состояние ковров и обивки, работоспособность кнопок и экранов. Оцени состояние салона от 1 до 10.»

#### Подкапотное пространство

> «Оцени подкапотное пространство этого автомобиля. Ищи: подтёки масла и антифриза, состояние ремней и патрубков (трещины = старение), чистота (слишком чистый = мыли перед продажей, скрывают утечки), ржавчина на болтах и креплениях, состояние проводки, следы ремонта (неоригинальные детали, герметик), уровень жидкостей. Оцени состояние двигателя от 1 до 10.»

#### Колёса и днище (если есть фото)

> «Проанализируй фото днища и колёсных арок. Ищи: ржавчина на элементах днища, состояние защитных чехлов, течи масла из КПП и двигателя, состояние тормозных дисков (борозды = износ), ржавчина на тормозных механизмах, состояние рычагов подвески, повреждения порогов и лонжеронов.»

### Таблица красных флагов на фото

| Признак | Что означает | Влияние на оценку |
|---------|-------------|-------------------|
| Разный оттенок краски на панелях | Перекраска после ДТП | -10 баллов |
| Неравномерные зазоры между деталями | Ремонт после ДТП | -15 баллов |
| Шагрень разной зернистости | Частичная перекраска | -8 баллов |
| Слишком чистый двигатель | Мойка перед продажей, скрытые утечки | -10 баллов |
| Потёртый руль при малом пробеге | Скручен пробег | -20 баллов |
| Провисающий потолок | Затопление или курение | -8 баллов |
| Мутные фары | Возраст, пескоструй, большой пробег | -5 баллов |
| Ржавчина на болтах | Возраст, неудовлетворительное хранение | -5 баллов |
| Разные шины на осях | Экономия владельца, возможны проблемы | -3 балла |
| Трещины на лобовом стекле | Замена стекла (возможно ДТП) или износ | -5 баллов |
| Личные вещи на фото | Реальный владелец, не перекуп | +5 баллов |
| Много фото, все ракурсы | Честный продавец, не скрывает | +5 баллов |
| Фото ПТС/СТС в объявлении | Прозрачность, можно сверить VIN | +5 баллов |
| Отсутствие фото подкапотного | Скрывают проблемы с двигателем | -8 баллов |
| Стоковые/каталожные фото | Не реальная машина, возможно мошенничество | -20 баллов |

### Генерация отчёта по фото

```
## Фото-отчёт: {Марка} {Модель} {Год}

### Кузов: 7/10
- Обнаружена перекраска заднего бампера (разный оттенок)
- Зазоры равномерные, признаков серьёзного ДТП нет
- Несколько сколов на капоте (не критично)
- Фары прозрачные, состояние хорошее

### Салон: 8/10
- Износ руля соответствует пробегу 65-75 тыс. км
- Сиденья в хорошем состоянии, без провисаний
- Потолок ровный, без провисаний
- На фото видны личные вещи — реальный владелец

### Двигатель: 6/10
- ВНИМАНИЕ: подкапотное пространство слишком чистое — возможно, мыли
- Заметны следы герметика на клапанной крышке (ремонт?)
- Рекомендуется проверить на СТО

### Общая фото-оценка: 7/10
Можно рассматривать. Рекомендуется осмотр с толщиномером ЛКП и проверка на СТО.
```
